# Web 版验收记录

日期：2026-11-01。检查对象为 Web 版 2.0.0，环境为 macOS、Node.js 23.11.0、npm 11.12.1，以及 Playwright 驱动的 Chromium。仓库要求 Node.js 22.18 或更新版本，CI 配置使用 Node.js 24；本地结果不代表已在所有支持版本与设备上验证。

## 自动检查

`npm run check` 通过：**214 项测试，0 失败、0 跳过**；31 份教材正文与附录通过公式排版、内部链接、源码链接、include 与旧运行说明检查；TypeScript 类型检查和 Vite 生产构建通过。`npm run format:check` 通过。

检查覆盖以下内容：

- 章节算法的独立手算、边界与不变量，包括权重重建、共享边覆盖、裁剪属性、深度、透视插值、法线、阴影比较、射线合法根与曲线曲面。
- 35 道参考练习。学生版本仍保留明确的 TODO；`npm run exercise -- 04` 会报告未实现函数，`--solutions` 通过。
- 55 个聚焦演示的注册与正文对应。通用演示检查初始、中间和结束帧、有限坐标、像素尺寸、公式，以及面板承诺的参数端点和选项；相机样章单独检查场景输出。
- 10 个三维综合实验实际生成图像；相机、物体、正交与透视、反射权重及高光参数影响正式成像。
- 综合实践的像素查询、提交顺序与线性颜色超采样。命令行以 64×64、每像素 4 个样本输出 PPM 和像素 JSON。

这些测试检查明确的数值与几何关系，不构成对所有输入的形式化证明。通用参数检查分别改变单个控件，没有穷举所有参数组合。

## 浏览器检查

生产构建通过本地静态预览访问，逐章加载 15 章，共确认 70 个章节演示；数学、术语、参考资料和综合实践附录可以访问。该轮检查没有未捕获页面异常、失败的资源请求或 `/api/` 请求。

实际操作验证包括：

- 重心坐标控制点、三维向量正交视图和经纬图控制点拖动，数值联动与撤销。
- 三维物体轴柄移动、相机环绕、正交缩放、通道切换与像素检查。
- 曲线演示播放；章节切换、目录收纳、实际 TypeScript 源码高亮及文件入口。
- 综合实践的 PNG 导出，以及第 12 章反射权重改变后正式图像随之更新。

布局检查包含 1440 像素桌面，以及 1024×640、768×844、390×844 视口。第 02、03、07 章与数学、术语页面在所检查尺寸下没有整页横向溢出。桌面浏览器模拟窄屏不能代替真实触屏设备测试。

额外将 `dist/` 挂载在纯静态 HTTP 服务的 `/graphics-book/` 子路径下：第 12 章、延迟加载的三维引擎、Worker、源码、字体和站点图标均正常加载；调整材质参数改变正式像素，没有 404、页面异常或后端计算请求。此检查不依赖 Vite 开发服务的路由回退。

## 构建与发布边界

- 生产目录约 3.5 MB，包含自带公式字体与运行依赖许可。三维模块按需加载；其单独压缩前块约 604 kB，Vite 仍给出超过 500 kB 的体积提示。该提示没有被隐藏，也不是运行错误。
- 正式软件成像运行于 Worker。高分辨率或复杂场景仍可能耗时，当前以终止过期任务避免旧结果覆盖新编辑，尚未提供渐进分块进度。
- Three.js 空间视图使用近似材质；教学算法图像才是光照、过滤、阴影与反射的核对依据。
- 当前树不含旧 Python 运行文件、uv 配置或虚拟环境；旧版保留为本地 Git 归档。npm 依赖、构建结果和验证截图不提交。
- GitHub Actions 与 Pages 工作流已配置，但本轮没有推送或执行远端部署。公网访问、部署权限与真实移动设备仍需在发布时验证。
