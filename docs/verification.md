检查覆盖以下内容：

复验日期：2026-11-02。

- 十五章在 390 px 窄屏逐一展开检查；另检查变换、纹理、纹理函数、光追在 390、768、1024 px 下的正文与演示宽度。公式拼接修复后，所检查页面没有横向溢出。多面板切换、移动工具菜单、目录遮罩和点击小节后收起侧栏正常。
- 从小节目录进入后继续滚动，再跨章返回、后退及刷新，可恢复位置；一次复验前后均为正文滚动 8241 px。字号改为 20 px、专注阅读、参数与相机状态恢复、完整源码高亮均可用。
- 在算法成像中实际拖动相机，撤销后恢复初值；在空间视图用轴柄将球 A 的 x 从 −0.95 移至 −0.33，G/R 工具切换正常。

在本机 Apple M4、16 GB 内存、Chromium、Vite 开发服务下，对第 15 章默认 384×384 场景修改球 A 反射权重：三次首帧预览分别为 **69、69、74 ms**，完整图像为 **893、903、876 ms**。连续 20 次输入、每次间隔约 50 ms，在 1040 ms 内观察到 15 帧预览。最终以相同参数独立调用核心算法，显示画布的 RGBA 与计算结果逐项相等。

这些数字是已载入页面上的输入至结果测量，包含浏览器调度，不是跨设备性能承诺；完整图像时间包含等待操作停止的 260 ms。此前本机测量的首帧约 84–85 ms，结果随运行状态波动。

## 当前构建边界

- 生产目录约 3.7 MB，包含自带公式字体与运行依赖许可。三维模块按需加载；其单独压缩前块约 631 kB，Vite 仍给出超过 500 kB 的体积提示。该提示没有被隐藏，也不是运行错误。
- 软件成像运行于 Worker。拖动时提供最高 128×128 的交互预览，停止 260 ms 后补齐所选分辨率；高分辨率或复杂场景仍可能耗时，尚未提供逐块进度。
- Three.js 空间视图使用近似材质；教学算法图像才是光照、过滤、阴影与反射的核对依据。
- 当前树不含旧 Python 运行文件、uv 配置或虚拟环境；旧版保留为本地 Git 归档。npm 依赖、构建结果和验证截图不提交。
- GitHub Actions 与 Pages 已通过公网验收；真实触屏设备仍需进一步试读。
