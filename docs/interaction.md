# 书内演示的交互约定

阅读页保持浅色背景、正文宽度和章节导航。演示使用独立的深色画布、较安静的网格和明亮的数学对象；演示始终留在相关推导中，不单独拆成工作台。

视觉参考 [3Blue1Brown 的线性变换讲解](https://www.3blue1brown.com/lessons/linear-transformations/)：用运动中的网格解释变换，用稳定颜色追踪同一个量。坐标轴、视角罗盘和变换轴柄统一为 X 蓝、Y 绿、Z 红；黄色表示当前操作与强调。颜色配合字母和文字使用，不能作为唯一标识。未复制其图片或视频。

## 二维与数学图解

- 拖动圆形手柄修改实际数学参数。选中点在画布下方显示两个坐标，可以拖动数值微调，也可点击输入精确值。坐标属于当前子图；相关参数约束仍由各章的手柄定义决定。
- 拖动空白区域平移，点击画布后滚轮围绕指针缩放。未激活画布时，滚轮用于阅读。双击空白、Home 或“适应”恢复视图；加减按钮提供无滚轮入口。
- 手柄支持 Tab 聚焦和方向键移动，Shift 方向键微调；拖动中的 Escape 取消。触屏可用双指缩放。
- 动画保留时间轴，可以逐步拖动；播放到结尾停止，速度可切为 0.5×、1×、2×。离开演示区域时暂停。
- 撤销／重做记录参数与视图快照。它不是持久编辑历史；关闭标签页后不承诺恢复。
- 桌面参数较多时在侧栏内滚动，画布与视图工具条保持紧邻；窄屏将参数按两列自然展开。CSG、八叉树和曲面截线通过切片中的手柄联动。
- 进阶几何图的空间子图可直接拖动环绕，右键或 Shift 拖动平移，方向键旋转视角；观察角度与参数面板双向同步，支持撤销。二维参数域、权重图和控制点保持各自的直接编辑语义。对应子图由 `orbitPanels` 显式指定，不按图形外观猜测维度。

## 三维综合实验

- “算法成像”显示教学函数计算的像素；“空间视图”用于选择、操作和检查几何。“对照”共用相机与场景状态，但材质不同。
- 鼠标直接拖动物体，在当前观察平面内移动。拖动空白或按 Alt 拖动可环绕，右键平移，激活画布后滚轮缩放。触屏单指环绕、双指缩放／平移，轻点选择物体后可使用轴柄或数值面板编辑。
- G、R、S 切换移动、旋转、缩放；轴柄可切换世界／局部坐标。吸附使用移动 0.25、旋转 15°、缩放 0.1 的步长；直接拖动物体时按住 Shift 临时吸附。
- 参数面板分为“实验参数”和“物体”。选择物体后显示位置、旋转和缩放；点击数值输入，拖动数值调整，Shift 拖动减慢十倍。光源与控制点使用同一套选中逻辑。
- 视角罗盘切换六个轴向，中心恢复原视角；1／3／7 对应正／侧／顶视角。F 聚焦选中物体，Home 查看全部；相机沿轨道平滑过渡，尊重减少动态效果的系统设置。
- Ctrl／⌘ Z 撤销，Ctrl／⌘ Shift Z 重做。操作说明、像素检查与计算详情折叠在演示底部，避免持续遮挡画面。

## 实现边界

数学核心仍在 `src/chapters/`，没有引入 UI 框架。`number-field.ts` 统一数值编辑，`history.ts` 保存有上限的独立快照，`scene-guides.ts` 只画辅助坐标和罗盘。语义色转换仅作用于图解；纹理与教学算法输出的 RGB 不做主题改色。空间预览的地面、阴影与材质仅帮助判断空间关系。

光追章的解析球要求均匀缩放，因此一个缩放分量会同步到另两个分量；不是把椭球当作球求交。实时预览与完整成像仍调用同一套核心函数。高分辨率最终结果的延迟、真实触屏设备和屏幕阅读器的进一步验证见 [验收记录](verification.md) 与 [后续计划](TODO.md)。
