## 当前结构

本版固定为连续十五章、79 个聚焦演示、15 个综合演示和 35 道编程练习。基础缺口插入已有概念之后；具有独立问题链的主题再增章。调整章号时，正文、目录、源码和练习一起更新，主题网址保持稳定。

| 阅读阶段 | 章节 | 应能解释的问题 |
| --- | --- | --- |
| 图像与空间 | 01–03 | 像素、坐标、姿态与相机如何关联，连续投影为何产生消失点 |
| 样本归属 | 04–06 | 图元如何离散、采样为何产生误差、整物体筛选与逐样本深度有何区别 |
| 表面颜色与管线 | 07–11 | 法线、光照、纹理、阴影如何与前面各阶段共同生成像素 |
| 几何表示与编辑 | 12–14 | 内外与连接如何表示形体，数据与控制点如何构造曲线，导数与曲率如何度量形状和接缝 |
| 从像素追踪光路 | 15 与综合实践 | 如何查询同一场景并解释有限反射 |

四元数为动画准备姿态插值，半边为几何处理准备连接关系，Hermite 与 de Boor 为曲面和运动路径准备求值工具。基础篇先讲清这些接口，不在同一小节提前展开整个后续专题。

## 本轮终止判断

以下条件同时满足后固定 v2.1.0，不再为未约定的专题延后发布：

1. 四项基础内容有正文、实际求值的交互及独立数值核对；误差、退化与模型边界写清楚。
2. 十五章的先修、编号、回引、导读与章末检查一致；新内容接入原有问题链，术语索引匹配当前接口。
3. 全部 94 个演示在生产构建中生成结果；新增演示实测拖动、参数联动、撤销、源码高亮及窄屏切换。
4. 核心函数与界面分离，测试、正文检查、类型检查、格式与构建通过，无验收中发现的阻塞问题。
5. GitHub 检查和 Pages 部署通过，公网复验通过；发布固定标签、Release 与静态包，保存验收记录。

这里的“完成”指约定的基础篇。完整课程覆盖、真实触屏适配的进一步验证和新增专题属于后续计划；不能用仍有可扩展内容作为永不结束的理由。

## 写作与实现约定

每节先明确沿用的输入与约定，再提出一个新问题。读者先预测、操作演示、查看中间量，再通过必要的推导解释结果。公式之后给可手算的检查和边界情形；收尾说明这一结果在下一节怎样使用。

正文文件按主题拆分，但读者看到连续的一章。`[[include:...]]` 可嵌套且检查循环；小节顺序由正文决定，不在渲染器中写特殊章号。新节完成后核对目录、引用、公式、源码入口和前后章转场。

核心计算使用短函数与普通数组，不增加算法基类或演示插件框架。先保留清楚的参考实现，再说明活动边表、二分区间定位、局部半边更新等优化；性能技巧应建立在已理解的数学对象上。

## 每批完成的条件

- 有教学单元和调用核心函数的交互，不用静态截图替代可操纵的过程。
- 检查依据来自手算、不变量、几何关系或另一种求值方法，不在测试中照抄实现。
- 本章可以连读，编号和“上一节／下一节”不失效。
- 桌面与窄屏可操作，实际源码可打开并高亮，既有章节回归通过。
- 覆盖表明确实现范围、缺口与近似，完成验证后发布。
