# 后续计划

v3.0 的范围是 39 章的模块化教材：基础成像、几何处理、光传输、图像处理、计算摄像、风格化和动画。实际 GPU 编程不在本书范围。统一记号、教材语气、跨章复用、可操作示例和诚实的实现边界是持续要求，见 [编写规范](editorial-standard.md)。

## 已纳入进阶版

- [x] 16–22：细分、离散算子、简化、参数化、形变、获取与规则建模。
- [x] 23–27：辐射度量、材质、辐射度、蒙特卡洛路径与 BVH。
- [x] 28–31：抠图、梯度域编辑、删缝、单应与稳健配准。
- [x] 32–34：透镜、传感器、噪声、编码反演、光场与光谱。
- [x] 35–36：图像抽象、笔画、样本纹理和时间一致性。
- [x] 37–39：关键帧、旋转、关节、蒙皮、积分器、粒子与群体。
- [x] 全书导读、转场、折叠目录与术语索引同步扩展；四元数等跨章算法直接复用。
- [x] 建立本校课程逐单元实现边界与 GAMES101 主题映射，保留原基础篇审查档案。

## 可独立深化的专题

下列条目不计为已经实现，也不以堆积文字追加到当前章节。

- [ ] 路径追踪的直接光源采样、MIS、俄罗斯轮盘赌、复杂介质与光谱外观；新增时须区分方差和截断偏差。
- [ ] 更多可检查的几何案例：非规则 Butterfly、完整重网格循环、ABF/球面参数域、多分辨率编辑与 Poisson 重建。
- [ ] 一般刚体接触、布料、流体与偏微分方程求解；先建立稳定性和约束的学习路线，再增加规模。
- [ ] 二维完整抠图、视频删缝/拼接、真实光流与时间一致性；现有一维或已知运动例保留作独立核对。
- [ ] 摄像设备标定、真实 RAW、颜色匹配与感知专题；当前合成测量不能代替设备实验。
- [ ] 完整水彩、语义笔画、ETF 与多尺度纹理合成；目前局部参考算法不冒充论文完整系统。
- [ ] 核对本校平台没有独立 PPT 的光追视频/课本要求，以及 GAMES101 的逐页细项和作业对应；主题对应不等于完整课程替代。

## 阅读与计算体验

- [ ] 读者试学，依据实际卡点改写手算和自查；进阶编程练习另成可验证任务，不把参考函数机械挖空。
- [ ] URL 参数分享与导出快照；同一标签页内的状态恢复已经实现。
- [ ] 进阶图的空间手柄与联动继续按问题增加；避免无限扩大参数面板。
- [ ] 高样本 CPU 路径成像的渐进分块与取消机制，配套更大输出；当前小图保留噪声和样本计数。
- [ ] 屏幕阅读器、纯键盘三维编辑和真实触屏设备验收。

v2.1.0 基础篇与 v3.0.0 扩展版使用独立标签固定。进一步研究方法是后续专题，不应把已完成版的启动、阅读、参考算法和静态部署再次变成无限任务。
