# 课程对照：教学内容与实现边界

2026-11-02，进阶扩展版。对照本地归档的北京理工大学智慧树《计算机图形学》课程：10 个模块、53 个平台知识点、51 份 PPTX、1037 页。本书现有 39 章与六个进阶模块；实际 GPU 编程按约定排除。

这里分别记录**已讲授的问题**与**可运行的参考实现**。小规模算法、局部模板、方法比较与完整生产系统不是同一种覆盖程度；不将“使用 WebGL”“能够播放”或论文名称当成教学覆盖。基础篇的逐页定位、既有公式核查与发现的差异保存在 [v2.1 审查档案](course-coverage-v2.1.md)。

本轮重读新增模块相关课件的提取文本，结合原作者资料核对公式、条件与方法层次，再对照本书实际函数和交互。没有逐页视觉核验全部 1037 页，也没有获得缺失的光追视频或题库。下表的章节表示实质教学入口，不表示复刻课件中的每套研究系统。

## GPU 单元的范围处理

10-01 的执行与存储层次、吞吐量/延迟在 11 章讲授；不做产品型号史。10-02 的 CUDA 程序组织与实际内核、10-03 的 GPU 建模、10-04 的 GPU 遍历与绘制实现按用户范围排除。其中独立于硬件的 NURBS、八叉树、重建思路、BVH、辐射度算法已归入相应正文。使用 WebGL 预览不计作完成这些 GPU 编程课件。

## 统一与纠偏

- 坐标继续使用右手系、列向量、相机 −Z；二维光学剖面和图像数组另标方向。
- 四元数统一为 `(w,x,y,z)`，37 章直接复用 02 章。曲线参数与物理时间用链式法则连接。
- 辐射通量 Φ 用 W，辐照度 E 与辐亮度 L 保留不同单位；辐射度自发射用 B_e，不与入射 E 混淆。
- 离散拉普拉斯统一正半定符号；质量矩阵、对角归一化和边界条件分别说明。
- 课件中的“主动扫描破坏对象/不受材质影响”“原始点云直接运行 Marching Cubes”“被动捕捉等于无标记”“粒子不反射光”等不作为通用结论。
- 摄像课件把 CCD 发明与登月相机混为一谈；本书按发明者的 1969 年记录说明器件来源，不沿用该产品史断言。其他未经核验的“世界第一”不据此扩写。
- 历史错误对照、B-spline 阶次、圆柱高度、Phong 含义等详细页码见 [基础篇档案](course-coverage-v2.1.md)。统一编写约定见 [editorial-standard.md](editorial-standard.md)。
