## 视觉与信息层级

书页保留柔和纸白与深墨色正文，演示采用克制的墨蓝画布。专业感来自对齐、尺度、清楚的对象关系和可靠反馈，不依靠密集边框、发光效果或装饰卡片。章节标题可沿用衬线字体；界面统一使用现有无衬线字体，数值与代码用等宽字体，公式继续由 KaTeX 排版。

- 正文桌面 17–18px、窄屏 16px；行宽约 36–42 个汉字，行高约 1.85。演示可越过正文列宽，但标题与正文保持共同对齐线。
- 控件和主要图内标签桌面至少 13px，触屏至少 14px；辅助元数据也不低于 12px。字号按最终显示尺寸核验，不能只看 SVG 内部声明值。
- 蓝色标几何/第一种量，绿色标对照/第二种量，暖黄标当前探针或活动项；颜色不能独自承担身份信息，轴、曲线与图像仍有明确名称。避免每个参数使用不同强调色。
- 只保留一层演示标题栏：题目、撤销/重做、恢复、专注查看。源码与导出放次级操作区，集中帮助继续收纳，不在每张画布重复铺设指南。
- 公式紧挨它解释的图形或读数。长推导留在正文；当前公式过长时可展开查看，不能把结果图缩小来给三行公式腾位置。

## 桌面布局

按演示容器的实际宽度决策，不能只根据整个浏览器宽度；章节侧栏收起后应自然利用增加的空间。

**容器至少约 1100px：** 主画面占余下宽度，右侧保留 280–300px 的检查面板。Python 正式成像是默认判读对象；成像相机操作与图像使用一致的构图。需要剖解相机、法线、包围体或光路时，进入“空间”视图；成像缩略图可展开，而不是长期维持两个竞争的大视口。显式开启“双视图”时才并排，并同步选中对象/像素。一次切换不得重置场景、探针或撤销历史。

**容器约 720–1100px：** 保留一个充足的主画面；检查面板收进右侧抽屉，展开后明确占用空间。不要继续维持两个狭窄视口加一列小字面板。

过滤、着色等聚焦比较默认使用 2×2 或并列结果，每张有效图像至少约 240px 宽；若装不下，就切换为选定两项比较。模型/纹理姿态、采样位置与显示缩放共用一份状态。局部足迹和数值显示在图组旁边；用连线、同色探针或轻量高亮说明对应关系，不重复罗列两份读数。

## 窄屏布局

容器低于约 720px 时，按阅读顺序安排“标题与模式 → 一张主图 → 当前关键控制 → 可展开的数值/参数”。主图宽度使用可用书页宽度，390px 屏幕上应至少约 340px；高度随内容而定，不保留无意义的固定空场。

比较模式采用一张大图上的 A/B 分界，或明确选出的两图上下排列；四种算法仍可通过名称切换，所有选择保留。A/B 的完整名称放图外固定位置，不能依赖两块截断浮标。数学图按内容重新排布面板、标签和公式：例如 mip 层级可以分行，频谱与信号上下排列。保留缩放和平移作为深入查看能力，但正常阅读不能要求用户先捏合才能看清文字。

参数使用演示内部的底部抽屉，默认只显示当前对象/当前实验的少量关键项。触控目标至少 44×44px，数值输入不会让抽屉遮住正在操作的控制点。书页滚动与画布手势要分开：未激活演示时单指滚动书页；显式进入操作状态后单指操作、双指缩放/平移，退出或点击画布外恢复阅读。切换必须有轻量可见状态，不能无提示吞掉整页触摸滚动。

## 统一操作规范

| 意图 | 规范 |
| --- | --- |
| 选择与编辑 | 点击对象/控制点选中；直接拖动产生可见结果。W/E/R 只在当前演示聚焦时作用于移动/旋转/缩放，输入框内不截获字符。不可用操作有就近原因。 |
| 相机与二维视图 | 保留现有三维空白或 Alt 拖动旋转、Shift 拖动平移；二维空白/空格拖动平移；滚轮缩放以光标为中心。F 聚焦或适配。只影响当前视图。 |
| 精确值 | 拖动数值粗调，Shift 精调，双击或 Enter 输入；显示单位和合法范围。滑杆适用于连续量，分段按钮适用于少量离散方案；不把所有动作塞回表单。 |
| 历史与取消 | 一次拖动等于一次撤销；Ctrl/⌘Z 撤销，Shift 重做，Esc 取消未提交操作。更换查看方式或打开参数不写入场景历史。 |
| 图像比较 | A/B 两侧由用户明确选择；定格显示来源、参数摘要和生成时间。两图使用同一像素坐标、显示缩放及曝光/颜色编码；更换相机后保留定格，但明确标为旧状态。 |
| 像素检查 | 点击图像得到真实 Python 像素及其计算链；同一探针联动各结果。提供适配、100%、200% 显示；整数倍像素检查使用最近邻放大，并显示原始分辨率，避免浏览器缩放滤波混淆算法差异。 |
| 计算反馈 | 拖动时标记“预览”，完成时标记正式分辨率；旧帧不得伪装成最新状态。耗时只在轻量状态栏显示，错误就近说明并保留上一次有效结果。 |

参数面板固定三种语义：选中对象属性、实验/渲染设置、当前探针读数。初始只展开与本节问题有关的一组；场景树可收纳。主动操作对象后再显示相关属性，避免学生先读完一整列参数才能开始。主图与数值使用相同单位和符号；源码按钮继续定位实际 Python 函数，不跳到只有桥接逻辑的文件。

## 实施与验收顺序

先用 07 的四过滤器实验重做图像比较和窄屏布局，再用 06 的着色频率及 12 的可移动场景验证同一规范，最后扩展到全书。不要先全站换色，再把尺寸和操作问题留到最后。

1. 在 1440×900、1024×768、390×844 及 360×800 实测；章节侧栏分别展开/收起。检查主图尺寸、最终字号、留白、图例与公式，不以“没有横向溢出”作为唯一标准。
2. 不打开帮助完成：选对象 → 拖动 → 精确输入 → 移动相机 → 点击像素 → 选择 A/B → 定格 → 撤销。记录阻碍、误触和状态丢失；学生应能辨认当前改的是物体、相机还是显示比例。
3. 用 06 保证三种着色共享网格轮廓与探针；用 07 保证四过滤器共享 UV/显示比例、足迹仍对应真实像素；用 12 保证 Python 最终图与相机操作一致。布局变化不得改写这些数值关系。
4. 检查连续输入期间确有多次 Python 结果到达、松手完成正式图像、Esc 不被迟到结果覆盖。将交互响应、Python 计算和显示更新分别记录，不用浏览器预览帧率代表后端性能。
5. 检查键盘聚焦、可见焦点、触摸滚动退出、最大化返回阅读位置、源码打开再返回；同一控件在主实验和聚焦演示中遵守相同规则。
6. 留下桌面/窄屏前后截图及操作录像，逐项记录通过或待修。至少复核当前全部 54 个聚焦演示与 15 个综合演示的布局；三章样例通过只证明设计可行，不等于全书界面完成。


## 2026-09-23 · 第 13 章实机复核

本批扩展完成后，使用实际运行的第 13 章复核了设计依据。无页面异常与无横向溢出仍不能证明布局合格：

| 浏览器宽度 | 正式 Python 图像实际尺寸 | 与学习任务的冲突 |
| --- | --- | --- |
| 1440px | 350×350px | 空间预览宽 521px，正式成像面积和视觉主次不足 |
| 1024px | 221×221px | 两视口与参数列继续挤压，通道换行 |
| 390px | 142×142px | 先铺 348px 预览，成像很小，常驻参数又占约 424px 高度 |

通道文字约 9px，观察方式约 10px，对象与数值约 11px，工具按钮多为 25×25px。像素记录在窄栏中不断换行；阶段图在窄屏仍把最终图像和七阶段整体缩小，图像约 110px。最新证据：[桌面渲染器](../../outputs/studio/design-review-13-1440-demo.png)、[中等宽度](../../outputs/studio/design-review-13-1024-demo.png)、[窄屏](../../outputs/studio/design-review-13-390-demo.png)、[像素面板](../../outputs/studio/design-review-13-1440-probe-panel.png)、[窄屏阶段图](../../outputs/studio/design-review-13-390-pipeline-stages.png)。

实施分成两条共享组件线：

1. **主渲染器以 13 章验收。** 同位置切换成像/空间，双视图由读者主动打开；成像保留相机手势与像素检查。参数固定为“实验 / 对象 / 像素”三个语义页，场景树归对象，深度/剔除/提交顺序进入管线折叠组。13 的首屏只露出分段、波幅和片元程序。像素页按原三角形→插值→候选深度→颜色排列，避免直接倾倒原始字段。
2. **聚焦演示以 07 四过滤器与 13 阶段图验收。** 真正重排图像、阶段和读数，窄屏大图优先；阶段选择高亮对应真实数据，完整全帧计数可以展开。保持数学与 Python 返回数据一致，再迁移到其余图。

已有拖数值、精确输入、W/E/R、撤销和集中帮助应保留；帮助中重复的对象编辑说明合并。格式化精确读数时仅减少显示小数位，不舍弃内部参数精度。布局切换不得重置场景、选中对象、探针与历史；页面仍是教材，源码和可操作演示仍在相关段落内。
