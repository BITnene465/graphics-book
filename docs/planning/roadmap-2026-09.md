## 分批建设

| 批次 | 必须完成的内容 | 交付检查 |
| --- | --- | --- |
| A · 整理光栅主线 | 图形学全貌与数学导入；把基本采样/抗锯齿接到像素覆盖之后；补着色频率、完整管线、MIP/三线性/各向异性过滤与纹理的其他用途 | 学生能解释一个三角形从模型到像素的全过程，并在同一场景里区分覆盖、深度、着色和过滤 |
| B · 补齐几何 | 表示方法、距离场与布尔组合；分段曲线、连续性、Bézier 曲面；细分、简化、重网格化 | 必须操作真正的曲面/拓扑算法，不能把增加球面经纬线当作网格细分 |
| C · 射线与加速 | 球/平面/三角形求交、反射/折射、自相交；包围盒、空间划分、BVH 构造与遍历 | 逐步检查访问节点和命中；加速与暴力结果一致，报告相交次数及实际耗时 |
| D · 光的传输与材质 | 辐射度量学、立体角、BRDF/BSDF、渲染方程、全局光照；蒙特卡洛与路径追踪、光源采样、俄罗斯轮盘；材质、复杂外观及高级传播方法 | 从方向/面积样本追到 PDF、权重与像素；可重放固定种子的路径，区别偏差、方差和预算 |
| E · 成像与感知 | 镜头、焦距、光圈、景深、曝光、运动模糊、光场；颜色匹配、色度图、色域、感知与显示 | 使用射线和采样解释画面，不以屏幕模糊冒充薄透镜模型；颜色转换注明光谱/RGB近似和显示限制 |
| F · 动画与模拟 | 关键帧、运动学、蒙皮、质点弹簧、常微分方程积分；碰撞、刚体、粒子与网格流体基础 | 时间轴可暂停/单步/回放；拖动约束与初始条件；对照时间步长、稳定性、能量和约束误差 |
| G · 基线上的增量 | 数值稳健性与误差预算；进一步的采样策略与多重重要性采样；跨管线复用与综合作品；性能和实现取舍 | 明确对应的基线概念、新增能力和可检验收益，不能把课程已经包含的内容改名算增量 |

按 A→B→C→D→E→F 建立学习先修关系；各篇可独立开发，但发布前必须补好承接。G 中与当前内容紧邻的数值误差实验可随篇增加，其余在相应基线完成后推进。每批交付正文、数学构造、可操作程序、可读 Python、练习和验证证据，避免先批量添加标题再补教学。

高级外观和复杂传播应保持课程的广度，并标明模型范围：可用小型、可核对的 Python 实验讲清算法，不承诺生产级毛发、皮肤或流体渲染器。不能只放一个名词或静态效果图就将主题标成已覆盖。

## 全书共同约束

- 书页承载讲解与运行中的演示，章节侧栏可收纳；不另建独立工作台，也不添加顶部练习/资料模式。
- 演示跟随概念出现，每章的数量按教学需要决定。优先直接操作、分步过程、可检查的数学量与受控对照。
- 数学、正式渲染、采样与模拟由 Python/NumPy 实现。前端负责排版、输入、可视化和即时预览，模型近似必须说清楚。
- 核心函数不依赖界面框架；按需复用普通函数，保持 `uv` 环境与本地资源，无需增加引擎、注册框架或 GPU 运行前提。
- 已写正文、算法可运行、界面可操作、整体验证通过分开记录。只有达到 [覆盖标准](../../docs/teaching/lesson-design.md#覆盖与完成的标准) 才能关闭对应缺口。

## 出版与部署

内容与界面逐批改进，整体设计继续独立验收。本批已有主图扩大、字号统一和手机最大化修复的实际证据，当前界面仍不视为全书设计验收通过。具体问题、桌面/窄屏布局及操作规范见 [渲染界面设计审查](../../docs/planning/renderer-design.md)。重点是书页与画布的比例、工具栏和参数面板的层级、可读的对照结果、直接拖动的即时反馈，以及统一的字体、间距与科学图形标注。桌面和窄屏均需实际操作并检查，不能以算法测试代替视觉与交互验收。继续保持演示嵌在教材中，帮助按需展开。

已支持本机双击 `start.command`，或 `uv run --locked python tools/serve.py` 一键打开。继续维护源码高亮/下载、参数恢复、撤销、窄屏与键盘操作。

公网发布在内容与交互稳定后独立交付：进程托管或单容器、环境重建、域名与 HTTPS、HTTP 反向代理、并发预算和外网验收。当前服务使用标准库 HTTP/JSON，不需要 Panel 的 WebSocket 配置；历史 Panel 界面只作为兼容入口。未完成这些工作前不宣称已经一键公网部署。
