# 渲染与数学约定

适用于 Python/NumPy 参考实现、PyTorch CPU/MPS、教学公式与浏览器预览。需要时在课堂显式展示约定。

## 空间、矩阵与数组

- 世界和相机采用右手系，相机看向自身 −Z。列向量语义：`p_clip = P @ V @ M @ p_local`。
- 矩阵存储和乘法语义分开。若批量顶点按 `(N,4)` 行数组保存，解释 `(P @ V @ M) @ vertices.T` 等等价写法。
- 视图矩阵是相机姿态变换的逆。教学相机与解释图观察相机分别标注。
- 角度控件可显示度数，计算用弧度；坐标与距离说明单位或无量纲约定。

## 裁剪、覆盖与深度

- 先在齐次空间按 `−w ≤ x,y,z ≤ w` 裁剪，再除以 `w`；新顶点同步插值属性，再三角化。
- 03 先做线段裁剪，04 扩展三角形，不能仅因一个顶点越界就丢弃整个图元。
- NDC Y 向上，图像数组行号向下。适配层只翻转一次；鼠标到索引使用同一映射。
- 默认像素中心为 `(i+0.5,j+0.5)`；自由几何探针不一定是像素中心。
- 本课程自行选择 NDC Z `[-1,1]`、深度缓冲 `[0,1]`，要求 `0 < near < far`。这是教学实现约定，并非 PyTorch/MPS 强制的坐标系；接入原生图形 API 时显式转换。
- 以屏幕重心权重插值顶点 `z_clip/w_clip`，再映射到深度值，不重复套普通属性的透视校正。
- 共享边用一致的归属规则，明确绕序与 Y 翻转关系；退化三角形单独处理。GPU 张量版本也必须遵守。

## 属性与光照

一般属性的透视正确插值：

$$
a(P)=\frac{\sum_i\lambda_i a_i/w_i}{\sum_i\lambda_i/w_i}.
$$

04 的二维实验可令 `w=1`。06 直接求解析椭球上的可见点与法线，在各图像样本处计算局部光照；07 再把一般顶点属性通过三角形插值到像素。

法线使用相应位置变换线性部分的逆转置，插值后归一化。光照的位置、法线、光方向、视方向必须在同一坐标空间。非均匀缩放是必要的检查例子。

Blinn–Phong 高光指数不等于 PBR 粗糙度；简单环境项不等于间接光。PCF 过滤阴影比较结果，不是完整的物理软阴影；Bloom 不自动增加物体受到的光照。

## 颜色与图像

- 光照、颜色插值、滤波和累积在线性 RGB 中进行；颜色纹理解码、最终显示编码各一次。
- 法线、UV、深度等数据不做 sRGB 解码；数值标明颜色空间。
- 对照图固定同一颜色映射和值域，避免每张图自动归一化而隐藏差异。
- 内部颜色数组可为浮点 `(H,W,3)`；回传显示时明确格式，检查 RGBA 通道、透明度和上下方向。
- SSAA 的“2× 每轴”是每像素 4 个样本，“4× 每轴”是 16 个；显示画布缩放不能冒充抗锯齿。

## CPU/MPS 与数值检查

显示舍入不改变内部计算。CPU 参考与 GPU 对照声明 dtype、容差与设备；较高精度参考转换到 float32 后再区分算法错误和舍入误差。不承诺逐位一致。

零向量、奇异矩阵、近退化三角形、近平面和射线自相交要有明确处理。对照场景和种子固定；随机后端未必生成逐位相同序列，需要严格比对时共享预生成的样本输入。

至少验证矩阵顺序、近平面穿越、共享边、遮挡的绘制顺序无关性、倾斜棋盘格、非均匀缩放法线和最近射线交点。张量加速不能删除可检查的中间量。

GPU 耗时测量先预热并同步；计算、回读、数据编码和界面响应分开记录。任何 CPU 回退都要显式标注。
