# Web 版结构与数据流

## 一份计算，一组可追溯结果

本书的算法源头在 `src/chapters`。函数输入为数值、向量、矩阵、网格或数组，输出仍是普通数据；核心不依赖浏览器、界面或引擎。可从 Node 单独调用，也可在浏览器或 Worker 中调用。

聚焦实验由 `figures.ts` 调用核心，生成几何图元、栅格像素、手柄与数值。`FigureView` 将这些数据画成 SVG 与图像，并把拖动结果写回输入参数。数学读数不从截图反推。

综合实验由 `StudyState` 保存物体、相机与参数。`localScene()` 生成公共几何；空间视图交给 Three.js 绘制，算法图像交给 Worker 中的教学函数。两个视图的材质不同，空间视图用于编辑，算法视图用于验证。

`reader/render-client.ts` 一次只安排一个计算任务。持续编辑时，短预览允许完成，再取最新参数生成下一帧；停止 260 ms 后生成所选分辨率的完整图像。新的编辑会中止正在进行的完整成像，旧任务不能覆盖新结果。预览最多 128×128，阴影贴图也暂降至 128；完整成像使用原参数，两者调用同一个 `renderStudy()`。页面标明当前质量，完整成像结束后才允许导出。

完整光栅成像依次调用变换、齐次裁剪、子像素覆盖、插值、深度、片元计算和显示编码。阴影先从光源渲染一次深度；射线路径则从像素生成射线，求最近合法交点、阴影与有限次数反射。中间缓冲保留图元、位置、法线、UV 与深度，供像素检查使用。

## 坐标与颜色边界

- 数学采用列向量，矩阵用按行排列的数组储存。模型顺序为 `T Rz Ry Rx S`，Three.js 物体使用相同的 ZYX Euler 约定。
- 相机前方为 −Z，裁剪后 NDC 深度为 `[-1,1]`，光栅深度存为 `[0,1]`；无覆盖用 `Infinity`、图元 −1 表示。
- 几何屏幕坐标的 y 向上，数组行向下。转换只在明确边界进行；第 03 章线框 `viewport()` 与第 04 章光栅器的坐标约定在正文分别注明。
- 纹理存储的第 0 行在顶部，材质 UV 的 v 向上；阴影查询 UV 使用左上原点。
- 采样、光照、过滤与混合在线性 RGB 中进行，最后执行 sRGB 编码。深度和法线是数据，不执行颜色解码。
- 光线追踪的深度通道保存首次命中的射线参数，不等同于光栅深度。预览的深度灰度按可见范围拉伸，探针保留原始数值。

## 保持可读性

一个章节目录包含问题相关的短文件，扩展只在确有独立主题时拆出。没有组件框架、渲染器继承树或通用插件系统。核心函数注释说明单位、约定和关键数值条件；计算过程优先直接展开。

正文与源码通过显式演示编号连接。正文按章加载，三维引擎在需要三维综合实验时加载，源码阅读加载实际 `.ts` 文件。`scripts/content-check.mjs` 检查数学排版、内部链接与旧运行指令；章节测试检查算法性质与演示输入范围。

章节顺序只在 `reader/catalog.ts` 中定义，01–39 与正文和源码目录一致。链接用稳定主题名；旧数字链接由一张兼容表解析。内容检查同时核对章号、引用文字与链接目标。

章节内的主题通过 `[[include:...]]` 显式排列，可嵌套并检查循环；没有按特殊章号追加正文的逻辑。测试检查各章展开后的小节连续性，以及数据约束、Bézier 构造、曲线度量、Hermite、连续性、B-spline、de Boor、有理曲线之间的先修顺序。CSG、八叉树、拟合和曲率各有短小的独立算法文件，显示用的体素近似与连续集合判定分开。后续分篇与扩展方案见 [全书规划](expanded-edition.md)。

`reader/main.ts` 负责路由、两级目录、阅读位置和源码对话框。小节锚点取自标题。浏览器历史保存当前阅读锚点与偏移；同一标签页的 `sessionStorage` 保存各章位置及演示快照，关闭标签页后不承诺保留。字号单独保存于 `localStorage`。每种演示只暴露 `snapshot()` 与 `dispose()`，没有额外状态管理库。

聚焦图解仅在视口附近计算；动画离开视口后暂停，公式未变化时不重新排版。多面板图解在桌面并排，在窄屏切换；图中文字与手柄按实际屏幕尺寸绘制。

演示共用小型的数值拖动输入与有限撤销历史，不引入状态管理框架。`scene-guides.ts` 维护坐标辅助与视角罗盘；二维图的语义色转换由 `visual-style.ts` 完成，算法像素不参与主题变色。三维直接拖动用经过命中点、平行于观察平面的平面求交，物体位姿仍写回同一个 `StudyState`。细节见 [交互约定](interaction.md)。

正式着色按投影类型计算观察方向：透视使用 `eye−point`，正交使用 `eye−target`。后者与表面位置无关；方向归一化在光照／反射函数边界执行。正交相机沿光轴移动时，只要窗口大小保持不变且裁剪不变，表面高光与环境反射也应保持不变。

新增主题时，先在 `core.ts` 写独立计算，再将它接入 `figures.ts` 和正文；只有跨章复用的数学才进入 `math/`。本结构为未来课程留有 `content/` 层级，不提前建立多课程管理系统。

## 模块与共用算法

`book-scene/model.ts` 定义台灯关节、小球、桌面和独立初始状态；`geometry.ts` 用第 13 章的曲线求值生成灯罩。`render.ts` 组合 03/10/11/23 章的投影、阴影、光栅化与辐照度函数，保留实际对象、位置、法线、UV 和插值权重。`imaging.ts` 从这些输出生成覆盖真值和有限孔径求积，`motion.ts` 复用 38/39 章的运动学与振子。其余 `*-studies.ts` 与 `foundations.ts` 只把计算接到章节图解，未增加渲染框架。

图像处理读取渲染结果的副本，避免修改一章的像素污染另一章。各章参数独立，不要求按顺序解锁或继承操作。首尾静止状态共用相同参考帧，实验过程中由各章自己的输入重新计算。场景、表面与剖面坐标在绘图边界转换；不能为追求外观相似另外手绘一份不关联的数据。

章节元数据包含 module，正文位于 content/<module>/<slug>/lesson.md；目录、先修链接和下一章仍由同一个 catalog 控制。基础篇的数字旧书签继续按原主题解析，新链接使用主题名。目录的模块折叠使用原生 details/summary，加载章节时展开所在模块。

进阶核心共享 math/linear.ts、mesh.ts 和 image.ts，不引入求解器依赖。稠密求解用于明确的小规模问题；这些实现不以稠密矩阵存储方式处理任意规模的生产网格。37 章直接复用 02 章的四元数，36 章复用 30 章的最小接缝。

figures/advanced.ts 只负责数学网格投影、线性颜色显示和曲线绘图。网格示意采用面排序，不冒充正确处理所有相交面的深度渲染器。进阶小图直接计算，基础篇综合成像使用原 Worker；不能将两者的计算调度混称为全部异步渲染。

空间子图以 orbitPanels 声明可环绕的面板，FigureView 将手势写回同一组 azimuth/elevation 参数。二维参数域和图表仍平移，控制点继续优先直接编辑；不增加三维编辑器或另一套状态管理。
