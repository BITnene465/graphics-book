# 全书编写、记号与术语规范

适用于基础篇与全部进阶模块。正文、演示标签、公式、源码注释和练习共同遵守；新增概念先补这里及术语索引，再在局部定义必要的专用记号。

## 数学与数值约定

| 对象 | 统一约定 |
| --- | --- |
| 点、向量与法线 | p/x 表示位置，d 表示射线传播方向，n 表示单位表面法线；输入未单位化时明确注明。N 表示样本或对象数量，避免与法线混用。 |
| 坐标与矩阵 | 右手系，列向量；M、V、P 分别为模型、视图、投影矩阵，最右先作用。矩阵代码按行储存。相机看 −Z。 |
| 四元数 | 统一标量在前 q=(w,x,y,z)，复用第 02 章的 quaternion.ts；第三方库的 xyzw 只在适配边界转换，不引入第二份相反顺序的核心。 |
| 索引 | 代码及数学下标从 0 开始。几何屏幕 y 向上，图像数组行号向下；在明确的接口边界只转换一次。 |
| 深度 | z_view 为相机空间坐标，d 为正轴向距离，D 为 [0,1] 缓冲深度。射线参数另说明方向是否单位化。 |
| 表面与曲线参数 | u、v 为常用表面参数，曲线既有 t 保留其局部归一化定义；与有物理单位的动画时间显式区分。跨度改变时使用链式法则。 |
| 权重与齐次坐标 | λ_i 为重心权重；w 为齐次分量，w_i/ w_ij 为有理曲线曲面权重，首次出现注明含义。 |
| 光学方向 | ω_i 从表面指向来光方向，ω_o 从表面指向观察方向；它们与沿传播方向的射线 d 不同。散射角度、半球与法线朝向显式定义。 |
| 光学量 | Φ 辐射通量（W），I 辐射强度（W/sr），E 辐照度（W/m²），L 辐亮度（W/(m² sr)），f_r 为 BRDF（sr⁻¹），ρ 为无量纲反射率。不将以流明计的光通量与辐射通量混用。此处 W 是瓦特，图像宽度 W 则由上下文和单位区分。 |
| 颜色 | 算术、平均、滤波和合成在线性 RGB 中进行；显示前编码一次。法线、深度、UV 和权重不是 sRGB 数据。 |
| 时间与频率 | 物理时间用秒，步长 Δt 用秒；参数进度需说明归一化范围。采样频率、转速、帧率分别标单位。 |
| 随机性 | 可复现种子；密度函数的积分域、测度和单位明确。样本均值不等于单次结果，也不由单帧噪声外观证明收敛。 |
| 离散算子 | 统一采用 Lx=Σ_j w_ij(x_i−x_j) 的正半定符号；平滑为 x−λLx。若使用归一化邻域平均，标明权重和及稳定条件。 |
| 误差 | 区分模型近似、离散化、随机估计和浮点误差。有限显示采样不证明连续对象的全局性质。 |

统一不是要求一个字母在所有学科永远只承担一种含义；跨章复用同一对象时记号必须一致，局部复用字母时必须重新定义单位与作用域，禁止无说明地改变含义。代码参数名尽量对应公式中的量，常用英文全称优先于难懂缩写。

## 术语

首次出现采用“中文（英文，缩写）”，随后统一中文或已定义缩写。统一使用：光栅化、片元、纹素、透视正确插值、齐次坐标、结点（样条）、顶点（网格）、次数/阶数、控制点/样本点、辐照度/辐亮度、形状因子、正半定、反射率、双向反射分布函数、拉普拉斯算子、参数化、重网格、蒙皮、正向/逆向运动学。

光照模型与着色频率分开；过滤与重建的具体操作须给定义；几何细分与提高参数采样密度分开；物体刚体变换、几何形变和动画时间推进分开。正文不将“看上去相近”写成数学等价。

## 教材语气与每节组织

- 使用客观陈述、明确对象与条件；称“本章”“本节”“读者”，避免持续对话、宣传语或写作过程汇报。
- 先说明沿用哪些输入与结论，再提出本节的新问题；用一个可以观察或手算的小例子建立模型。
- 演示放在读者需要观察的推导旁边，一章可有多个演示。操作提示短且只涉及本图特有动作，共用手势由统一帮助承担。
- 定义量和单位后给公式；公式后解释各项的几何意义，并用独立算例、不变量或另一求值路线核对。
- 给出至少一个边界、退化或失败情形，说明算法能保证什么；不能用堆叠警告代替推导。
- 末尾给源码阅读顺序、自查问题和下一章如何使用本章结果。相关实现直接复用，不复制不同约定的版本。
- 内容验收优先于视觉完成度：关键推导不能依靠突然出现的矩阵或概率术语跳过步骤；先修缺口先补数学桥梁。每章提供可独立核验的算例，自查提示按需展开，帮助读者定位误解。演示是否漂亮不能替代是否解释了变量、结论与失败条件。

## 实现与审校

数学核心只接收和返回普通数据，不依赖 DOM 或 Three.js；图形适配层组织视图、手柄和数值。保留短函数与局部显式循环，不为新增章建立算法继承树或插件框架。

每批检查：术语表、公式符号、单位、数组轴、源码接口、演示读数、链接与章号。自动检查能发现拼写和结构问题；逻辑先修、公式适用条件和教材语气仍逐章人工审阅。
