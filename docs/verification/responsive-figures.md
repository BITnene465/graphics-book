# 书内数学图：分幅排版与输入验证

日期：2026-09-23。本轮保留正文中的实时演示，数学计算、纹理与成像仍由 Python 完成；没有新增依赖。它是界面打磨的一批，不代表全书视觉验收或 GAMES101 覆盖完成。

## 改动范围

13 个聚焦演示采用 Python 声明的 58 个子图。宽屏保留完整构图，画布高度随构图比例调整；容器低于 620px 时按语义分幅。默认单列，Mipmap 的小层级两列、三个混合色三列，避免每个色块占满一屏。原图坐标、参数和运算函数不因排版改变。

| 章节 | 演示 | 子图数 |
| --- | --- | --- |
| 02 | 三维向量、任意轴旋转、镜像/错切、一般变基、两连杆 FK | 14 |
| 07 | Mipmap、四种过滤、Ripmap、椭圆足迹、高度法线、Bump/位移 | 33 |
| 08 | 时间混叠、快门积分 | 11 |

`Drawing.panel(key, bounds, columns=1)` 只标记排版归属；开启分幅的构造必须给所有图元与操作柄分组。前端各子图有独立平移/缩放状态，首次范围在拖动时保持固定，F 重新适配。投影和鼠标逆映射使用同一子图范围；共用参数仍联动更新所有子图。小图不因同组其他图缩放而改变数值。

详细数值放进可展开的“数值检验”。删除图内重复统计，拆分长公式；集中帮助记录新的操作。普通滚轮滚动书页，Ctrl / ⌘ + 滚轮缩放数学图。触屏默认阅读，选择“操作图形”后进入编辑，结束后恢复阅读；按钮使用至少 44px 的触屏高度。混合设备的样式按 `any-pointer: coarse` 判断，但本轮未验证实体混合设备。

跨宽窄布局、F 适配或滚轮缩放发生在拖柄期间时，先取消该次拖动，避免旧坐标基准造成参数跳变。Esc / blur 可取消双指视图手势；释放第三触点后仍能继续双指操作。

## 实际验证

- `uv run --locked python tools/check.py`：全书 **384 项通过**。本轮没有新增算法，沿用原有独立数值检查及参数遍历。
- 13 个分幅演示：390px 下逐个拖动全部控制柄，按屏幕位移计算预期的 Python 参数改变量，检查轴映射与限制；逐次撤销恢复；390↔1360px 切换保留参数。见 [分幅与坐标记录](../../outputs/studio/responsive-figures-qa.json)。
- 44 个演示默认公式在 390px 下无内部横向溢出、无 KaTeX 错误或页面横向溢出。124 个选项分支公式通过严格 KaTeX 解析。见 [全目录布局检查](../../outputs/studio/figure-catalog-layout-qa.json)。这不是所有连续参数状态的字形碰撞保证。
- 真实书页的 02 一般变基、07 四种过滤、08 快门：桌面与窄屏布局、Python 源码定位和高亮通过，浏览器无异常。见 [书页记录](../../outputs/studio/reflow-book-qa.json)。
- 鼠标拖动期间的 F、Ctrl/Meta + 滚轮取消及下一次拖动通过；三面板缩放/平移后的投影往返误差不超过 10⁻¹⁵；跨断点取消、双指 Esc/blur、3→2 触点切换已独立复核。
- 真实 `/app?chapter=02` 的 390×844 Chromium 触屏仿真：默认滑动移动书页且不改参数；编辑模式拖柄发出 8 次 Python 请求，正确改动选中分量且不滚书页；退出后恢复阅读滚动。见 [手势证据及范围](../../outputs/studio/panel-gesture-qa.json)。没有把仿真称为实体触屏实测。
