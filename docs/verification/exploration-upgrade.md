# 场景探索升级验收

日期：2026-09-23。本文记录增加演示自由度和视觉对照的本轮变更；沿用书内演示与 Python 核心算法，不另建工作台。Python 数学测试与浏览器交互验证分别记录如下。

## Python 场景与正式成像

第 03 章两个可编辑物体新增立方体、球面网格、四面体选择。`cube_a_shape`、`cube_b_shape` 控制形状，既有位置、旋转、缩放参数保持兼容。对象的 `start/count` 随实际三角形数量变化；立方体 12 面片、四面体 4 面片，球面由第 10 章参数网格构造。正式颜色图新增深度缓冲和世界面法线通道，均来自同一次 Python 栅格化结果。四组预设呈现前后遮挡、近大远小、广角几何和平行投影。

第 12 章两球可分别选择线性底色、0—0.95 的镜面混合权重，并调节局部 Phong 高光强度及指数。高光系数默认 0，保留原实验默认输出；预设可以打开高光。镜面权重控制后续射线，Phong 控制当前交点的局部方向响应，二者独立。点光没有距离衰减，Phong 项也没有能量归一化，仍属于明确的教学模型。

`trace()`、`render_image()`、`trace_pixel()` 保持原调用兼容，新增材质关键字参数；`trace_path()` 提供同参数下的逐步解释。每段保存路径权重、局部颜色、镜面系数、实际继续权重和颜色贡献。零反射权重立即终止路径；预算耗尽时使用局部颜色近似。探针的贡献之和经过最终颜色截断、sRGB 编码，与正式图像中被检查的像素一致。

浏览器得到相同几何与底色用于交互预览。WebGL 预览的着色与 Python 最终渲染有各自用途；本记录没有将两者宣称为逐像素等价。
