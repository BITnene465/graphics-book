- 12 章沿同一书页呈现讲解、公式、交互演示、推导和原始代码；章节侧栏支持桌面收起与手机抽屉。

- 每个演示下方可以展开真实完整源码，带高亮、行号、复制和下载。源码文件树列出本章算法、复用算法和渲染桥。

## 运行与限制

默认启动：`uv run --locked python tools/serve.py`，或 macOS 双击 `start.command`。当前服务在 `http://localhost:5006/app?chapter=01`。

前端为本地原生 HTML/CSS/JavaScript，加固定版本 Three.js 0.180.0、Prism 1.30.0、KaTeX 0.16.22。运行不需 Node、前端构建或 CDN；Python 环境由 uv 管理。本次没有新增 Python 依赖或启用 PyTorch/MPS。

普通章节最高1024²，第01/03/06/12章最高2048²，第09章阴影图最高2048²。连续操作合并请求，过期结果不覆盖新状态；已开始的 Python 计算仍会完成。移动端已验证布局和鼠标模拟操作，尚未做真机多指手势覆盖。公网部署、HTTPS、多用户并发与MPS加速不属于本次已完成验收。
