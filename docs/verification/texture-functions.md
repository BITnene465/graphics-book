## 教学与算法

主实验使用 Python 针孔射线与解析球求交，镜面反射方向查询同一个原创环境：可直接求值，也可查经纬图或立方体图。旋转环境时，先把世界方向变到环境局部方向，再查固定基准图；探针报告的 UV 是实际访问地址。背景直接沿眼射线查询。

四个聚焦演示分别安排在方向坐标、反射推导、格点噪声、多尺度合成的讲解处：

| 演示 | 可直接操作 | 显示的计算 |
| --- | --- | --- |
| environment-direction | 全景 UV | 单位方向、六面选择、面内地址、立体角因子 |
| environment-reflection | 法线、朝眼向量 | XY 截面中的三维反射公式与环境查询 |
| value-noise-lattice | 查询位置 | 真实四角值、fade 曲线、四角权重及求和 |
| fbm-coordinate-space | 每层查询点、频率尺度、球体平移 | 三维函数切片、有限加权和、物体/世界空间对照 |

四个图组共 17 个子图、11 个操作柄，宽屏保持联动构图，窄屏按推导顺序重排。球面颜色为 192² 的真实 Python 图像，切片为 96²；主实验最大 1024²。每幅图可定位到实际构造函数，完整核心、测试和练习均可在章节源码区阅读。

环境核心、程序纹理、可视化构造分文件保存，均用普通 NumPy 函数。教材明确区分 value noise 与 Perlin noise、有限 fBM 合成与严格随机过程。前后章已补承接，不把第 13 章当作第 14 章的先修。

## 明确的范围

环境位于无限远，无局部视差；镜面只做一次方向查询。未实现粗糙度积分、HDR 曝光、重要性采样或完整全局光照。Cubemap 双线性过滤只在单面内 clamp，未实现跨面无缝过滤。程序纹理未做像素足迹过滤，高频可能混叠；视图最多四层，核心最多八层。

界面的主图比例、标注与字体、窄屏多图对照仍应继续打磨；部分辅助标注只有 11–12px。本次视觉检查确认指定画面可读和可操作，不把数值通过或章节增加视为最终设计验收。其余 GAMES101 单元、整书编辑审查与公网部署仍按路线推进。
