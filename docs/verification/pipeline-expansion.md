## 实际内容

| 学习问题 | Python 与正文 | 书内操作 |
| --- | --- | --- |
| 点积、叉积如何描述三维关系？ | 02 的 `spatial.py` 计算长度、夹角、正交投影和有向面积，明确零向量退化。 | `vector-products` 的 XY、YZ、ZX 三投影共享一对三维向量；六个手柄直接编辑对应坐标。 |
| 如何绕任意轴旋转？ | 从平行/垂直分解推导 Rodrigues，再构造矩阵，验证长度与轴向分量保持。 | `axis-rotation` 直接移动轴和点；播放同一空间圆在三投影中的运动。 |
| SSAA 与 MSAA 究竟共享了什么？ | 08 的 `multisample.py` 共用样本位置、覆盖、逐样本深度与线性 resolve；独立选择逐样本或按可见图元—像素的中心着色。 | `multisample-compare` 对比实际图像，`multisample-pixel` 显示真正的覆盖/赢家/深度/颜色缓冲及求值次数。可移动几何、改变高频着色和检查像素。 |
| 足迹在两轴上不同时怎样选层？ | 07 的 `footprint_filters.py` 生成真实二维 ripmap、连续双 LOD、四层查询与原纹素权重。 | `ripmap-axis` 独立拖 UV 与足迹方向，检查实际数组和四层混合。 |
| 椭圆如何决定每个纹素的权重？ | 有界 Gaussian 在第 0 层离散求和，包含归一化、clamp、退化回退；明确不等于包含重建核和 mip 加速的完整 EWA。 | `elliptical-footprint` 将真实椭圆贡献与 ripmap 原纹素贡献放在共同热图刻度下比较。 |
| 一个顶点如何到达最终像素？ | 13 的普通 `vertex_stage` / `fragment_stage` 接起变形、MVP、齐次裁剪、覆盖、透视插值、深度和颜色；`inspect_pixel` 回溯原顶点与候选记录。 | 综合演示可移动模型/相机/光，改变分段、波幅、片元程序、裁剪范围、深度时机、提交顺序和剔除；`pipeline-stages` 联动真实像素与全帧计数。 |
| 透明颜色为什么依赖顺序？ | 13 的 `source_over` 在线性 RGB 上执行不透明目标的 straight-alpha 混合，并手算两种提交顺序。 | `alpha-compositing` 同步拖动两图中的红层，调整 alpha，检查 Python 输出及中心颜色。 |

所有正式图像与数学都由 Python/NumPy 生成。新增核心不依赖 UI，继续沿用现有 `uv.lock`，无新增运行依赖。书内源码按按钮定位实际构造函数，并保留高亮、完整文件和被复用算法。

## 教学编排

阅读顺序变为 **01 → 02 → 03 → 04 → 08 → 05 → 06 → 07 → 09 → 13 → 10 → 11 → 12**。第 13 章先收束光栅数据流，再进入几何表示；文件标识与旧 URL 保持稳定。

02 的三维向量和任意轴旋转接在仿射/逆矩阵后；08 的 MSAA 接在覆盖、滤波和 Nyquist 后，并明确下一章才完整推导深度；07 的双轴/椭圆过滤接在 mip/各向异性之后。长章使用同目录小节文件嵌入正文，没有另开独立学习模式。章间过渡与新节内容经过交叉审查。

阶段图的播放只高亮当前阶段，图像及统计始终来自完整帧；右侧标注“全帧计数”，所选像素的权重/UV/候选深度另列。MSAA 播放移动一个像素，不累加帧，不冒充时间抗锯齿。透明混合是独立教学图，未把它宣称为主场景的透明网格排序或折射。

新增验证重点：

- Rodrigues 与独立四元数乘法比较 200 组任意轴旋转，最大误差约 `1.78e-15`；长度、轴向分量和零轴异常均有检查。
- SSAA/MSAA 共享 owner/depth，纯色时逐像素相同，高频着色时能不同；验证多个可见图元、背景、中心求值与计数口径。图中样本存储槽放大使用最近邻，不把它们平滑成不存在的颜色。
- Ripmap 检查四层手算、NPOT 层均值和原纹素权重重建；椭圆参考检查固定 UV 的方向变化、独立 clamp 加权和、空支撑/零轴回退。小纹理与有界足迹保证参考实现可检查，不隐瞒第 0 层查询成本。
- 管线检查解析波面法线与有限差分、原顶点权重重建、PNG/probe 一致性、提前深度测试的等像异耗、提交顺序、背面剔除和精确 near/far 边界。模型/相机/光修改确实改变 Python 图像，正式分辨率 1024² 也经过检查。
- 审查找到并修复近等深度下回溯与成像的舍入顺序差异：两处共用显式三项深度插值，保留严格小于规则；不添加 epsilon 掩盖矛盾。另核验 50 组极端参数及 1,398 个命中像素。
