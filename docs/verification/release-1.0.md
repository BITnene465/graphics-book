使用 Chromium 分别在 1440×1000 与 390×844 视口走完十五章：

## 运行环境与范围

默认环境为 Python 3.11、NumPy、markdown-it-py、mdit-py-plugins 与 mdurl；其中后四项为安装包，当前 macOS 环境约 27 MB。Panel/Bokeh 仅通过 `--extra legacy` 安装，GPU 依赖不进入默认环境。前端资源全部随源码提供。

源码下载包已解压到独立临时目录，重新创建四个包的环境，通过 HTTP 交付检查并运行综合实践。该副本的教材服务也已单独启动，第 15 章生成 512² 图像且没有公式错误。下载包的文件集合与 Git 跟踪集合一致，不包含原虚拟环境、实验输出或课程 PPT。

服务默认监听本机。GitHub 仓库分发完整教材与运行程序，不承诺 GitHub Pages 能执行 Python，也未交付公网托管、鉴权或多人并发部署。正式成像使用 NumPy；Three.js 负责即时三维预览；MPS 没有实现执行路径。
