# 01–06 章教学连贯性审查

范围：六章 `lesson.md`，以及第 04 章拼接到正文中的 `raster-lesson.md`。审查覆盖现有全部段落、公式、数值例子、代码片段、练习与章节承接；不修改本轮核心算法、界面或图像资源。动态标记只是接入点，播放器实现与交互验收由主任务完成。

## 本轮统一规则

- 先定义对象与坐标空间，再引入运算；公式后接具体数值或几何不变量，最后再讲异常情况。
- 几何叙事采用 x 蓝、y 绿、追踪点黄、错误对照红。真实 RGB 属性仍按其颜色含义解释，不能为了统一叙事把纯红数值改叫蓝色。
- 主演示用于综合问题；局部演示只承载紧邻的一项推导。每章一个 `main` 加两个不同的焦点 ID。
- 删去重复的鼠标、滚轮、按键教学和旧 Panel 控件路线；保留“先预测什么、比较哪个量、什么结果能证伪”的观察任务。通用操作见书页帮助。
- 保留列向量、正旋转逆时针、几何 y 向上、数组第 0 行在顶部等约定。对第 03 章 `viewport()` 的 y 向下连续屏幕接口，明确写出接到第 04 章前需要的转换。
- 四幅 SVG 的 Markdown 引用和重复图注已删除：`samples.svg`、`order.svg`、`projection.svg`、`areas.svg`。原资源文件未删除。
