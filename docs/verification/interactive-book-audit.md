# 交互教材本轮验收记录

日期：2026-09-23。此记录对应正文内的 24 个数学演示、12 个综合演示，以及可编辑三维对象。已验证事实与尚待整页验收的功能分别记录；[上一轮记录](studio-audit.md) 是历史快照，其测试数量和界面状态不自动代表本轮结果。

## 实现范围

- 12 章各配置两个聚焦数学问题的演示及一个综合演示，共 36 个。正文用独占一段的 `[[demo:id]]` 指定位置，`[[demo:main]]` 放置本章综合演示。第 04 章的共享边演示在续接的 `raster-lesson.md` 中。
- `teaching_figures.py` 用 Python/NumPy 计算矢量构造、公式、数值与控制点；`web/teaching-figures.js` 把返回的图元画为 SVG，传递播放进度及操作。正式成像和数值探针继续由章节核心与 `studio_render.py` 计算。
- 综合演示后设「展开本章完整源码」，提供实际文件、高亮和行号；数学演示的代码入口打开同一源码区中的 `teaching_figures.py`。完整文件与工程下载保留。
- 操作说明集中于帮助入口。页面层已实现撤销/重做、演示最大化、参数区收纳及视口比例调整；整页实际操作结果见下文。
- 继续使用 `uv.lock` 与原有 Python 依赖，无新增动画、SVG 或前端构建依赖。默认正式渲染为 CPU/NumPy；可选 PyTorch/MPS 未被启用。
