本轮补齐了采样、着色频率与纹理过滤的一组教学闭环。当前共 **12 个可运行章节、29 个聚焦演示和 12 个综合演示（41 个）、27 个 TODO 练习**。完整 GAMES101 仍在建设中；功能验证不等于界面设计验收完成。

## 实际交付

| 学习问题 | 正文和 Python | 书内操作 |
| --- | --- | --- |
| 一个像素应该平均哪个范围？ | 08 的 `core.py` 增加余弦信号的解析盒核卷积、积分和 sinc 响应；正文解释先过滤再采样和盒核旁瓣。 | `convolution-window` 直接拖窗口中心与右边界；播放逐段积分，观察完整滤波输出。 |
| 不同频率为何给出相同样本？ | 08 增加带复系数的频谱复制与碰撞合并，解释带相位的 Nyquist 边界；补复数/Euler 的必要桥梁。 | `sampling-spectrum` 拖信号频率和 Nyquist 边界，同时看曲线、样本与频谱；切换真实盒式预过滤。 |
| 在哪里计算光照会改变结果？ | 06 新增独立的 `mesh_shading.py`；Flat、Gouraud、Phong 共用同一网格、裁剪、覆盖、深度结果和 Blinn–Phong 模型。 | `shading-frequency` 并排三张 Python 图像，拖光源 XY、改变深度/网格分段/高光指数。主演示另可移动、缩放网格并检查真实像素权重、法线、三种线性颜色。 |
| 缩小纹理时应该查询哪一级？ | 07 增加线性 RGB mip 链、透视 UV 的解析 Jacobian、连续 LOD 与三线性；非二次幂尺寸使用等面积缩减。 | `mipmap-levels` 展示实际 16²→1² 数组，拖 UV 和 LOD，检查相邻两层查询及线性混合。 |
| 长条状足迹为什么不能只扩大方形过滤核？ | 07 用 Jacobian 奇异值描述局部足迹，短轴选 mip、长轴多点查询；明确 tap 上限、clamp、局部近似与非 EWA 范围。 | `texture-minification` 在同一平面并排显示四种 Python 过滤结果；四图共享可拖像素探针，联动局部足迹、LOD 与查询次数。主演示保留完整平面变换并增加过滤、源纹理分辨率及 LOD 偏移。 |

新增的构造函数集中在 06–08 各自的 `figures.py`，注册入口仍是 `teaching_figures.py`。SVG 中的位图来自 Python 颜色缓冲；浏览器只负责摆放与输入，不执行这些光照或过滤算法。无新增依赖，继续使用原 `uv.lock`。

源码按钮现在可以定位实际章节文件和函数行号，不再一律跳到总注册文件。非动画对照去掉无意义的播放条，重置放在演示标题旁；拖动后的读数限制显示小数位，计算参数保留原精度。

## 数学与接口验证

从 `graphic/` 执行：

```bash
uv run --locked python tools/check.py
```

最终 **290 项测试通过，0 个失败章节**：工具/集成 60，01–12 依次为 11、13、17、27、15、30、25、24、14、17、15、22。新增测试验证数学性质、独立参考和图像/探针一致性，并非按实现逐行生成期望值。

- 卷积与独立 Gauss 积分对照；DC、窄窗、负旁瓣、非整数采样率、带相位重合谱线均有检查。新采样演示另遍历 405 组控制参数/进度组合，结果有限。
- 网格着色检查共同覆盖、平面手算、窄高光遗漏、逆转置、法线归一化、裁剪后原始权重与真实求值计数。集成测试确认三通道 PNG 的选定像素与探针线性 RGB 编码完全一致。
- 纹理检查常量/均值保持、NPOT、商法则导数、连续 LOD、长短轴与独立像素积分参考。96²、倾斜 70°、512² 纹理、64 格的指定场景中，对 32×32 相机射线积分参考的线性 RGB MAE 约为：双线性 0.342、三线性 0.035、各向异性 0.021；这个算例不意味着各向异性对任意场景都有相同比例收益。
- 审查发现并修复了放大区 LOD 偏移的夹取顺序错误；A=1 和各向同性足迹在正负偏移下均退化为同一种三线性查询。统一了“直径 1 像素圆、完整跨度 σ、半轴 σ/2”的尺度表述。
- 完整像素四角跨过平面消失线时，精确四角足迹可能无界；`pixel_footprint` 明确拒绝非正透视分母，新图使用的是已注明的局部 Jacobian 近似。
