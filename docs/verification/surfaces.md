## 教学与 Python 实现

[正文](../../courses/graphics-foundations/modules/04-shadows-and-geometry/15-surfaces/lesson.md)从控制网的权重与边界进入两轮曲线插值，再引入偏导、切平面、局部面积、正则性及曲面拼接。高光与曲率用于检查接缝，数值诊断和整边控制点等式的保证分开解释。

| 位置 | 已实现内容 |
| --- | --- |
| `15-surfaces/core.py` | 张量积求值、两轮 de Casteljau、解析一阶/二阶/混合偏导、定向法线、面积倍率、H/K、均匀参数网格、整边 C0/G1/C1/C2 构造与采样诊断；纯 NumPy，无界面依赖 |
| `15-surfaces/render.py` | 复用已有相机、齐次裁剪、覆盖与透视属性插值；Python 生成光照、法线和平均曲率图；可关闭的等参线 |
| 综合演示 | 单块 16 点或双块 32 点三维控制网；控制点、相机和光源可直接操作，受约束的点可见但锁定；保留历史与精确输入 |
| patch-construction | 在参数方形拖动 u/v；比较两轮求值的中间控制曲线、实际等参线与结果权重 |
| patch-frame | 改变伸缩、弯曲和扭转；检查两个偏导、定向法线与局部面积映射，伸缩为零明确退化 |
| patch-seam | 拖动横截面控制柄并沿缝取样；比较全局横向导数、法线角和法曲率，切换约束及参数跨度 |

G1 的倍率 λ 明确定义为局部横向导数比例，因而全局导数满足 `DR = λ(TL/TR) DL`；其正比例构造是充分条件，不代表全部一般 G1。C1/C2 按跨度的一次/二次方缩放。退化点的法线与曲率由掩码标为无定义，不填造方向。两个 TODO 分别独立实现张量积求值和带跨度的 C1 控制行。

成像的覆盖与深度来自有限三角网格，法线与曲率在透视恢复的 UV 处解析计算。探针分别返回网格成像点、精确曲面点及位置差；网格变密不改变解析曲面，也不属于 Loop 等拓扑细分。光照中的双面薄片处理不改变法线通道或 H 的定向。平均曲率采用固定范围色标，范围外饱和；等参线是参数标记，不是几何边。
