# 坐标、表面与时间：基础缺口补充记录

日期：2026-09-23。本批在原有 13 章中新增 7 个聚焦演示，合计 **44 个聚焦演示 + 13 个综合演示 = 57 个**，练习保持 **29 个 TODO**。这一批补充坐标、表面与时间采样的教学闭环，不宣称完整覆盖 GAMES101，也不将 FK 或规定的匀速运动称为完整动画系统。

## 实际新增内容

| 章节与演示 | 数学与实现 | 明确边界 |
| --- | --- | --- |
| 02 `reflection-shear` | 三维偏移平面镜像、手性、简单错切；三个投影共享同一点与变换。 | 零法向显式失败；镜像过程中的点插值不是一组等距变换。 |
| 02 `general-basis` | 固定世界点、可平移的一般三维基；`solve(B,p-o)`、转置反例、条件数与退化状态。 | 二维投影重合不代表三维基退化；近奇异时暂停坐标求解是显示策略。 |
| 02 `two-link-hierarchy` | 父架到世界乘子架到父架；两杆 FK、世界/局部位移及杆长不变量。 | 无 IK、关键帧、骨骼蒙皮或动力学。 |
| 07 `height-normal` | 模型长度单位中的高度导数、右手正交切线架、法线数据编码和误用 sRGB 对照。 | 简化平面参数化；一般曲面还需法线导数，法线数据不是颜色。 |
| 07 `bump-displacement` | 原平面、Bump 与真实位移网格复用相机、光照、裁剪和深度；比较实际覆盖集合。 | Bump 不改几何，位移受网格采样限制；无环境映射或凹槽自阴影。 |
| 08 `temporal-aliasing` | 八重对称轮 +1 rev/s 在 12 fps 与 −0.5 rev/s 同像；记录时刻与连续运动同轴显示。 | 瞬时帧同像不自动延伸到非零曝光；Nyquist 边界方向不唯一。 |
| 08 `temporal-shutter` | 居中盒式快门、真实时刻中点求积、逐像素余弦/sinc 解析参考。 | 平均在线性 RGB 中；不使用空间模糊或历史帧；仍有有限求积和帧间混叠。 |

核心分别位于 `linear3d.py`、`hierarchy.py`、`surface_maps.py`、`temporal.py`，图形构造位于同目录主题 `*_figures.py`。最终图像与数学量由 Python/NumPy 计算，浏览器负责输入和显示，没有新增运行依赖。

02 的追加正文顺序为三维向量/旋转 → 镜像/错切 → 一般变基/父子层级；08 为多样本空间覆盖 → 第 12 节时间采样 → 第 13 节读码与练习，再接深度章节。07 保留高度、法线与位移的共同参数和单位说明。

## 本记录已持有的检查证据

- 时间核心的 11 项独立测试通过，覆盖逐采样时刻整图同像、Nyquist 端点、快门中点、零曝光/零速度、数值收敛和有限中点混叠反例。sinc 结果用独立正弦原函数与手算检查。
- 时间图的 144 组参数冒烟检查通过：帧率 4/12/40、正/负/零速度、占空 0/0.5/1、样本数 1/2/64；JSON 无非有限数，手柄逆映射正确，采样时整图最大差小于 $10^{-12}$。
- 默认快门探针的瞬时、两样本、解析亮度分别为 1.0、0.775、0.736074；整幅线性 RGB 最大误差约 0.0373694。误差仅比较时间求积，不包括空间像素面积积分。
- 新增 Python 文件与全局注册经过 Black 格式化。源码注册指向真实章节文件与构造函数。
- 四个新注册（一般变基、两连杆、时间混叠、快门）的 156 组完整参数/选项组合通过定向 payload 检查；44 个注册及 13 个主章节计数一致，四个来源文件与函数行号均能解析。
- 实际 `lesson_html` 展开后，44 个聚焦插槽各出现一次、13 章各有一个主插槽；02 与 08 的编号均为连续的 1–13。八份本批更新文档中的本地链接均指向现存文件。
