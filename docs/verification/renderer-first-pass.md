# 书内主视口：第一轮布局与操作验证

日期：2026-09-23。仍是正文中的实时演示，主入口没有迁移到独立工作台。本记录限定于 13 个综合演示；44 个聚焦数学图的响应式重排另行实施，不把主视口完成等同于全书界面终验。

## 本轮实现

- 三维章节默认以 Python 正式成像为主图；同位置切换“成像 / 空间”，双视图由读者主动打开。布局切换保留参数、图像通道、所选对象、探针和撤销历史。
- 检查面板分为“实验 / 对象 / 像素”；对象列表和变换属性归入对象页，点击成像像素切换至真实 Python 读数。第 13 章先展示分段、波幅和片元程序，管线状态等设置收纳为折叠组。
- 演示容器不足 1000px 时默认收起参数；展开为局部抽屉，可用参数按钮或 Esc 收起。明确操作目标、字号与数值对齐，清除旧的三列和窄屏布局覆盖，由 `editor-polish.css` 管理综合演示组件布局。
- 手机保留大图，通道按钮自动换行，参数不挤占图像宽度。粗指针设备明确切换“操作画面 / 完成操作”；非操作状态允许沿图片滚动阅读。
- 本章完整源码保留 Prism 高亮、真实行号和下载；手机把文件列表放到代码上方，代码字号 13px；桌面代码字号 14px。

算法与正式像素仍来自 Python/NumPy；没有加入 UI 框架、前端构建步骤或新的运行依赖。

## 成像画面的真实操作

在第 13 章管线、第 12 章光追实测：直接拖动物体改变 Python 几何参数；Alt 旋转拍摄相机；一次连续拖动只需要一次撤销即可恢复；Esc 能取消拖物或相机操作，迟到响应不会覆盖恢复的参数。两次约 0.7 秒的持续拖动各收到了 **6 次 Python 预览响应**，松手另生成正式分辨率结果。这里统计的是后端响应，不是 WebGL 帧率。

同一组物体拖动、相机旋转、撤销、取消、像素与对照检查也在 03、10 章通过（分别收到 6、5 次持续拖动预览）；见 [相机与几何补充记录](../../outputs/studio/renderer-interaction-extra-qa.json)。

还检查了 Shift 相机平移、滚轮改变拍摄距离、W 切入空间视图显示移动手柄，以及取消拖动后的正常单击。单击像素切到 Python 读数页，A/B 和定格继续可用。视图切换前后参数完全一致。触屏本轮验证了操作开关和 `pan-y` / `none` 的实际切换，未将其当作所有真实设备手势的保证。
