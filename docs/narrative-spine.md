# 台灯、小球与桌面：全书的实验主线

主线使用同一份几何、默认姿态、纹样和相机定义。青色折臂台灯、赭色斜纹小球与有刻度的桌面承担可识别的对象身份；每次回访解决一个此前尚未解释的问题。局部三角形、链、平面和振子继续用于隔离变量，不强行替换成完整场景。编排意图保留在这份维护文档中，正文直接讲对象、变量和问题，不提示“伏笔”或要求读者感到熟悉。

## 实现约束

- `src/book-scene/` 只提供场景数据、短的组合函数与章节演示；具体算法继续放在原章节。没有新的渲染框架或依赖。
- 图像处理的输入由同一三维模型实时生成，不另画一个相似的二维图案充数。
- 章节有独立、可复现的初始状态；从中间进入也能阅读。跨章关系由真实数据和明确引用建立，不要求先完成操作才能解锁。
- 每个回访必须有可改变的输入、观察量和核对条件。交互说明继续使用统一控件，不增加故事任务栏。
- 第一章与终章的静止参考帧使用相同参数与函数；自动检查像素一致性。源码入口可沿调用找到几何、采样与着色。
- 文本按“已知结论 → 未解决问题 → 实验 → 可验证解释”衔接。台灯不说话，叙事由读者理解的增长承担。

## 验收

核对首尾同帧、对象身份及关节长度；证明相机修改不改变几何、纹样修改不改变深度、图像处理确实读取场景输出。真实拖动灯头、小球、像素探针与曲面控制点；检查撤销、源码、桌面和窄屏。最后复读全书的开头、转场和章末，保证新增回访与本章推导互相解释。
