# v3.0 统一扩展版验收

日期：2026-11-02。本机 macOS、Node.js 23.11.0、npm 11.12.1、Playwright Chromium。CI 使用 Node.js 24。检查范围为 39 章、131 个聚焦演示与 15 个综合演示，另有综合实践及三个阅读附录。真实触屏与全部支持浏览器未逐一验证。

## 内容与实现

新增 16–39 共 24 章、52 个聚焦演示，按六个模块组织。章节开头声明前置对象，结尾连接下一问题；01 的导读、15 的基础篇回顾、39 的全书回顾和术语索引同步修订。所有正文编号使用统一分隔样式，命名链接与旧书签保留。

四元数统一为标量在前的 `(w,x,y,z)`，动画章直接复用 02 章；细分规则中的度数 m、离散算子的正号与归一化记号、形状因子术语、光学量的单位、图像数组方向与动画时间分别核对。将写作过程式措辞改为模型条件与适用范围。内容检查新增必需正文、术语别名和块公式分隔符检查。

修复检查中发现的问题：平行视线返回不可识别状态；同色前背景不生成伪 alpha；Fresnel 等折射率的掠射情形；均值坐标边界点；RANSAC 输入不足四点；极小非零射线方向的包围盒查询；散焦能量离散归一化；关键帧极值的显示范围。局部例子的边界详见 [课程对照](course-coverage.md)，不将研究方法介绍算作完整系统实现。

## 教学内容复核

以理解和核验为优先，再检查外观。数学补充由六节扩充为十节，补齐线性系统与零空间、最小二乘与固定变量、Jacobian/奇异值/特征模式、概率密度与方差；章节在实际使用处链接到对应小节。修正参数化章把拉普拉斯称作“上一章”引入的错误引用。

补写调和映射的邻点平均、LSCM 从重心基函数到矩阵两行的装配、Lambert 半球归一化积分、蒙特卡洛估计的期望与逆累积分布、泊松编辑的变分及离散符号。正文说明假设怎样进入公式，演示读数怎样对应结论。

16–39 章各增加一个核对算例和可展开的自查提示，并逐题核对提示确实回应问题。24 组算例使用实际核心函数、独立数值求积或解析关系逐一核验通过：包括立方体细分角点 5/9、十点链能量 1/18、二面片辐射度 (64/63, 8/63)、最小接缝成本 3、薄透镜弥散圆 1/6，以及三种积分器的一步能量。随机噪声的比较使用统计容差，不要求某次随机结果恰等于理论值。

单样本的样本方差不可估计。修正原先返回零的实现，改为返回空值并显示“至少需要两个样本”；以在线离均差更新方差，相关测试同时核对两个采样分布的解析方差。增加样本数不被表述为消除路径截断偏差。
