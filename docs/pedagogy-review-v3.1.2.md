# v3.1.2 初学者阅读复审

2026-11-02。按阅读顺序审阅 39 章、章节补充与四个附录，共 71 份 Markdown，并对照实际算法及演示。重点是先修概念、公式中间步骤、可执行的观察任务；不增加课程范围。

## 概念与推导

- 变换章节补充转置、单位矩阵、内积、列空间与奇异值的局部定义；用压缩第三分量的例子解释条件数。镜像推导不再提前依赖特征值术语；Slerp 从两端点张成的平面与圆弧插值得到正弦权重。
- 采样章节补充半平面覆盖公式的面积推导；Bézier 与拟合分别解释二项式系数和 Frobenius 范数。纹理章节先解释偏导再引入 Jacobian，环境映射在首次使用处定义立体角及球面面积因子。
- 拉普拉斯章节用三点链展开矩阵，区分显式一步的 1/2 与隐式一步的 2/3。参数化从旋转与统一缩放的 Jacobian 推到保角残差；双目重建从两幅像坐标相减得到视差。
- 光传输逐项解释两个余弦、面积到立体角的换算、BRDF 中的 D/F/G，以及概率密度如何进入路径权重。给出折射角、远场辐照度与反射链的数值例子。
- 抠图补充已知颜色时的最小二乘推导，修正“前景色等于背景色即无解”为“alpha 无法确定”；泊松编辑从邻边差分推到像素方程。单应、双边滤波、弥散圆、逆向运动学与数值积分补齐变量含义或中间计算。

## 正文、接口与演示对应

- 修正 sRGB 函数被描述为直接接收整幅图像的问题，明确逐分量接口及 `encodeRgba()` 的职责；修正颜色平均图的左右布局与编码值含义。
- 修正点变换的数组形状、旧版层级变换函数名、纹理构造函数参数，以及 JavaScript 中不能使用的 `counts[rows,cols]` 索引写法。
- 像素采样图明确为独立局部示意；边界探针区分 UI 夹取与核心拒绝越界。相机实验不再要求选择不存在的顶点探针，区分固定像素与固定空间点。
- 深度图说明与实际显示统一：可见深度范围拉伸，近亮远暗；像素探针仍报告原始深度值。
- Ripmap 操作改为实际存在的横纵 LOD 控制；椭圆足迹图补齐同一 UV、足迹下的 Ripmap 对照。两张权重图共用色阶，显示真实贡献、峰值位置、归一化检查与最终颜色。
- UV 演示扩大可操作范围，使两倍缩放和反向映射均可复现；左右面板使用相同坐标尺度。
- 微表面图增加可拖动的观察方向、半程向量与 D/F/G 读数。原先默认 BRDF 曲线几乎缩成一个点，改用明确标注的对数与峰值归一化；原始 BRDF 和峰值单独报告，不能从显示高度比较能量。
- 折射图标注上下介质并显示折射角、临界角；路径追踪开放 0 次反射，让读者区分直接看到环境与表面反射。
- 演示恢复旧阅读状态时合并新参数默认值，保留已保存参数，避免新增观察方向导致旧页面状态报错。

数学核心与依赖不变。演示继续调用原有纯函数；新增计算只组织图形与读数，没有引入另一套算法或交互框架。
