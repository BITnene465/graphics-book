# 图形学中英术语与符号索引

本索引按主题收录中文术语、英文名称、缩写与符号。章节编号链接到对应正文；相关公式见[数学补充](?appendix=math)，接口组合见[综合实践](?appendix=capstone)。

## 统一约定，以及必须显式转换的接口

| 项目 | 本书约定与接口边界 |
| --- | --- |
| 世界与相机 | 右手系；相机看自身 −Z，前方点通常有 `z_view < 0`。正轴转向按右手规则；02 的二维正旋转是逆时针。见 [02][02]、[03][03]。 |
| 矩阵 | 列向量语义：`matVec(compose(P, V, M), pLocal)`，最右边先作用。矩阵按行储存，向量是普通数组；储存方式不改变作用次序。 |
| 点与方向 | 三维点补齐次分量 1，方向补 0；二维仿射使用 3×3，三维仿射使用 4×4。法线另用可逆线性部分的逆转置。 |
| 裁剪与除法 | 齐次裁剪范围 `-w <= x,y,z <= w`；先裁剪图元，再对有效正 `w` 做除法。NDC 三轴取 `[-1,1]`，深度缓冲把 Z 映射到 `[0,1]`。见 [03][03]、[06][06]。 |
| 屏幕与数组 | NDC 的 Y 向上，通常图像数组 `[row, col]` 的 row 向下。03 的 `viewport()` 直接返回左上原点屏幕坐标；04 的 `clipToScreen()` 返回 Y 向上的几何坐标，`rasterizeTriangle()` 再输出行向下索引。这两种输出不能直接互换。 |
| 像素中心 | 左上数组像素 `[r,c]` 的连续屏幕坐标为 `(c+.5,r+.5)`；若几何屏幕 Y 向上，则为 `(c+.5,H-r-.5)`。共享边的 top-left 判断须匹配采用的 Y 方向。 |
| 解析采样网格 | [07][07] 的 `ellipsoidSurface()` 从顶部开始生成行。最终像素数组、Canvas 图像与 PNG 都以顶部为第 0 行；不得在显示时再次翻转。 |
| UV 与图像归一化坐标 | [08][08] 的颜色纹理 UV 原点在左下，而纹理数组行向下；[10][10] 的阴影查询 UV 原点在左上，匹配阴影深度数组。`math/image.ts` 的 `makeImage(u,v)` 使用左上原点像素中心，v 向下。几何参数域不自动继承图像数组的方向，接口之间须明确转换。 |
| 角度 | [02][02] 的 `rotation(angle)` 接收弧度；[03][03] 的 `perspective(fovYDegrees, ...)` 接收度数。[12][12] 的椭球参数 `u,v` 是弧度；[08][08] 的圆柱 UV 和 [14][14] 的示例参数域则归一化到 `[0,1]`。以函数签名和公式定义为准。 |
| 颜色 | 光照、颜色插值、滤波和累计在线性 RGB 中完成；输入 sRGB 颜色先解码，最终显示再编码一次。法线、UV、深度等数据不做 sRGB 解码。 |
| 缺失数据 | 深度背景常用 `+inf`，物体编号用 `-1`；世界位置等不存在的属性可能为 `NaN`。先用 `owner >= 0` 选表面，再参与计算；不能把背景深度解释成真实表面。 |

## 图像、颜色与采样

| 中文 / English | 含义与常见混淆 | 章节 |
| --- | --- | --- |
| 像素 / pixel | 输出图像的一个离散位置及其值；本书用盒式面积平均建立入门模型。一个像素可以由多个样本估计。 | [01][01]、[05][05] |
| 样本 / sample | 在指定位置对连续场景的一次求值。样本数、输出像素数、显示放大倍数是不同量。 | [01][01]、[05][05] |
| 线性 RGB / linear RGB | 相同照明量相加与平均所用的颜色表示；线性不是指屏幕坐标插值方式。 | [01][01] |
| sRGB 编码 / sRGB encoding | 用分段传递函数把线性颜色映射到显示编码值；不是简单的固定幂 `gamma=2.2`。 | [01][01] |
| 滤波 / filtering | 按权重组合一片区域的值；纹理查询中也称“过滤”，颜色运算在线性空间进行。 | [08][08]、[05][05] |
| 盒式滤波 / box filter | 对矩形范围使用常量权重。本书一个像素内的等权平均近似其面积积分。 | [05][05] |
| 超采样抗锯齿 / SSAA, supersampling anti-aliasing | 每个输出像素内部多次求值再合成；每轴 n 个样本的规则网格共有 n² 个样本。 | [05][05] |
| 抖动采样 / stratified jittered sampling | [05][05] 将像素划成小格，每格内随机取一个位置，固定种子可复现。不是把图像随机移动。 | [05][05] |
| 混叠 / aliasing | 不同连续信号产生相同或误导性的离散样本；空间阶梯、摩尔纹、移动时闪烁均可能是表现。 | [05][05] |
| 带限 / band-limited | 信号不含超过某个上限的频率；理想采样定理依赖此条件，锐利边缘通常不满足。 | [05][05] |
| 奈奎斯特频率 / Nyquist frequency | 采样率 $f_s$ 的一半；本书采用 $f_s>2f_{\max}$ 表述避免临界相位歧义。 | [05][05] |
| 重建 / reconstruction | 从离散样本形成连续表示，或依据样本估计输出值；有限样本不能自动恢复已丢失细节。 | [05][05] |

## 空间、相机与变换

| 中文 / English | 含义与常见混淆 | 章节 |
| --- | --- | --- |
| 基 / basis | 线性无关的一组方向；坐标是相对于基的系数。二维变换矩阵的两列可看作基向量的去向。 | [02][02] |
| 仿射变换 / affine transform | $p'=Ap+t$，包含平移与线性变换，保持直线及仿射组合。 | [02][02] |
| 齐次坐标 / homogeneous coordinates | 增加一个分量统一表达仿射变换与投影；`w` 不总为 1，也不是额外的空间轴。 | [02][02]、[03][03] |
| 奇异矩阵 / singular matrix | 不可逆矩阵；零缩放把维度压扁，会丢失信息。接近奇异还可能放大数值误差。 | [02][02] |
| 奇异值 / singular value | 单位圆或单位球经过线性映射后的主轴半径；最大、最小值分别表示最大的拉伸与压缩倍率。 | [02][02]、[19][19] |
| 条件数 / condition number | 可逆矩阵的二范数条件数为最大与最小奇异值之比，衡量求解对相对误差的敏感程度；不等于当前计算已经产生的误差。 | [02][02] |
| 模型矩阵 / model matrix | 局部坐标到世界坐标。 | [02][02]、[03][03] |
| 视图矩阵 / view matrix | 世界到相机坐标，是相机姿态的逆；`lookAt()` 构造它。 | [03][03] |
| 透视投影 / perspective projection | 通过除以深度产生近大远小；本书相机的 `w_clip=-z_view`。 | [03][03] |
| 正交投影 / orthographic projection | 图像横纵缩放不随深度变化；[10][10] 平行光的阴影相机采用它。 | [03][03]、[10][10] |
| 裁剪空间 / clip space | 尚未除以 `w` 的齐次坐标空间，图元在此与六个半空间求交。 | [03][03]、[04 光栅化][04-raster] |
| 归一化设备坐标 / NDC | clip 坐标除以 `w` 后的坐标；本书可见体三轴范围均为 `[-1,1]`。 | [03][03] |
| 视口 / viewport | 将 NDC 映射到连续屏幕坐标的矩形区域；尚需像素覆盖判定才能得到图像。 | [03][03]、[04 光栅化][04-raster] |
| 近远裁剪面 / near and far planes | 规定保留的相机轴向距离范围；不是把越界深度简单截成 0 或 1 就完成裁剪。 | [03][03]、[06][06] |

## 覆盖、插值与可见性

| 中文 / English | 含义与常见混淆 | 章节 |
| --- | --- | --- |
| 重心坐标 / barycentric coordinates | 三角形三个顶点的仿射权重，和为 1；内部点的权重非负。 | [04][04] |
| 边函数 / edge function | 二维有向面积表达式，判定点位于有向边哪一侧；可同时得到覆盖与权重。 | [04 光栅化][04-raster] |
| 光栅化 / rasterization | 将投影图元变成覆盖样本以及属性；一个像素可能接收多个候选片元。 | [04 光栅化][04-raster] |
| 片元 / fragment | 某图元在一个采样位置产生的候选颜色、深度等信息；通过深度测试后才可能写入图像。 | [04 光栅化][04-raster]、[06][06] |
| 顶边左边规则 / top-left rule | 共享边恰好归给一个相邻三角形的约定；公式依赖屏幕 Y 方向及绕序。 | [04 光栅化][04-raster] |
| 子像素量化 / subpixel quantization | 04 将屏幕顶点固定到 1/256 像素网格，以整数边函数保持共享边归属一致；会轻微改变几何。 | [04 光栅化][04-raster] |
| 仿射插值 / affine interpolation | 属性按屏幕权重直接求和。二维或正交情形适用，通常不能直接插值透视后的普通属性。 | [04][04]、[08][08] |
| 透视正确插值 / perspective-correct interpolation | 插值 $a/w$ 与 $1/w$ 后相除；适用于 UV、世界位置等普通属性。 | [08][08]、[10][10] |
| 深度缓冲 / depth buffer, Z-buffer | 记录当前最近存储深度；[06][06] 默认用严格 `<`，相同存储深度由先提交者保留。 | [06][06] |
| 深度争夺 / Z-fighting | 不同表面落入相同或接近的存储深度，产生不稳定可见性；受深度精度和 near/far 影响。 | [06][06] |
| 画家算法 / painter's algorithm | 先远后近绘制；本书整面平均深度排序是故意保留的失败对照，不能解决相交图元。 | [06][06] |
| 视域剔除 / frustum culling | 用包围体与视锥范围排除肯定在视域外的物体；留下的候选不保证可见。 | [06][06] |
| 层级深度 / hierarchical Z, Hi-Z | 在近小远大的约定下保存区域最大深度，以候选最近深度证明整片覆盖均被挡住；背景和范围必须保守处理。 | [06][06] |
| 小物体剔除 / small-object culling | 按投影尺寸主动省略细节，允许改变图像；小于一个像素仍可能覆盖样本。 | [06][06] |

## 执行与并行

| 中文 / English | 含义与常见混淆 | 章节 |
| --- | --- | --- |
| 顶点着色器 / vertex shader | 处理顶点位置与属性；经过图元装配、裁剪和光栅化后才生成片元。 | [11][11] |
| 片元着色器 / fragment shader | 计算片元输出；是否写入帧缓冲还受深度、模板、丢弃和混合等规则影响。 | [11][11] |
| 吞吐量 / throughput | 单位时间完成的工作量，不等于单个任务的响应延迟；也不同于光追中的路径权重。 | [11][11] |
| 锁步与分歧 / lockstep and divergence | 通道共同推进指令，部分通道可能等待；本书用迭代成本模型解释，不将模型周期当作 GPU 实测时间。 | [11][11] |

## 表面、纹理与光照

| 中文 / English | 含义与常见混淆 | 章节 |
| --- | --- | --- |
| 法线 / normal | 垂直于局部切平面的方向；光照前归一化，变换时用线性部分的逆转置。 | [07][07]、[12][12] |
| Lambert 漫反射 / Lambertian diffuse term | 教学明暗项包含 $\max(0,n\cdot\ell)$，$\ell$ 从表面指向光源。 | [07][07] |
| Blinn–Phong | 用半程向量 $h=\operatorname{normalize}(\ell+v)$ 构造经验高光；指数不等于 PBR 粗糙度。 | [07][07] |
| 环境项 / ambient term | 本书用于保留暗部可见性的简单常量，不是间接光照计算。 | [07][07]、[10][10]、[15][15] |
| 方向光 / directional light | 表面各处使用相同入射方向；[10][10] 的光源观察位置定义方向及取样体积。 | [07][07]、[10][10] |
| 点光源 / point light | 方向随表面位置变化；[07][07] 可使用平方反比衰减，[15][15] 的基础核心为隔离变量采用恒定强度。 | [07][07]、[15][15] |
| UV / texture coordinates | 表面属性到二维纹理域的坐标；不是屏幕像素坐标，也不天然决定原点方向。 | [08][08] |
| 圆柱映射 / cylindrical mapping | 用方位和高度生成侧面 UV；接缝两侧位置相同、地址不同，轴上的方位无定义。 | [08][08] |
| 纹素 / texel | 纹理数组中的一个离散元素；与输出图像像素不必一一对应。 | [08][08] |
| 最近邻 / nearest-neighbor filtering | 根据 UV 选择一个纹素；纹理越界在本章采用 clamp。 | [08][08] |
| 双线性过滤 / bilinear filtering | 对四个邻接纹素加权；不等于对整个像素足迹做面积积分。 | [08][08] |
| 像素足迹 / pixel footprint | 一个输出像素在纹理域覆盖的区域；倾斜、缩小时可能跨过许多纹素。 | [08][08]、[05][05] |
| 阴影映射 / shadow mapping | 第一遍从光源记录深度，第二遍把可见世界点投到光空间作比较。 | [10][10] |
| 深度偏移 / shadow bias | [10][10] 从接收点归一化光深度中减去非负值；其单位不是世界距离。 | [10][10] |
| 阴影痤疮 / shadow acne | 表面对自己的阴影图采样产生错误遮挡；浮点误差和两张图取样位置不同都会影响。 | [10][10] |
| 阴影脱离 / Peter Panning | bias 过大放过实际遮挡，使接触阴影脱离或消失。 | [10][10] |
| PCF / percentage-closer filtering | 多次比较深度，平均通过比例；不能先平均深度，也不是完整物理软阴影。 | [10][10] |

## 几何、曲线与射线

| 中文 / English | 含义与常见混淆 | 章节 |
| --- | --- | --- |
| 三角网格 / triangle mesh | 顶点和三角形索引组成的离散表面；绕序决定面法线方向。 | [12][12] |
| 隐式表示 / implicit representation | 用 $F(p)=0$ 描述表面；$F$ 的数值一般不是到表面的距离。 | [12][12] |
| 参数表示 / parametric representation | 用 $p(u,v)$ 生成表面点；球的经纬参数在极点会退化。 | [12][12] |
| 梯度 / gradient | 标量场的偏导向量；非零梯度在隐式表面上给出法线方向。 | [12][12] |
| 构造实体几何 / constructive solid geometry, CSG | 用集合的并、交、差组合内外判定；构造树的括号和差集次序会改变结果。采样显示不等于精确网格布尔运算。 | [12][12] |
| 八叉树 / octree | 将三维盒递归划为八个子盒；整盒分类、未决叶盒与单点采样是不同层次的判断。 | [12][12] |
| 半边 / half-edge | 将定向面的边拆成有向半边，通过 next、twin 等连接查询邻接关系。 | [12][12] |
| 样本插值 / data interpolation | 要求曲线通过指定参数处的样本；参数分配也是问题的一部分。 | [13][13] |
| 最小二乘拟合 / least-squares fitting | 在约定的模型与参数下最小化残差平方和；固定参数残差不等于最近点距离。 | [13][13] |
| Bézier 曲线 / Bézier curve | 控制点通过 Bernstein 权重组合成曲线；内部控制点一般不在曲线上。 | [13][13] |
| de Casteljau 算法 | 对控制点逐层线性插值，最后得到曲线点；同时能构造精确分割。 | [13][13] |
| Bernstein 基函数 / Bernstein basis | $B_i^n(t)=\binom ni t^i(1-t)^{n-i}$；在 $[0,1]$ 非负且和为 1。 | [13][13] |
| 凸包 / convex hull | 包含控制点的最小凸集；Bézier 曲线在参数 $[0,1]$ 上位于其中。 | [13][13] |
| 弧长 / arc length | 沿路径累计的长度 $\int\|C'(t)\|dt$；均匀参数不意味着均匀弧长。 | [13][13] |
| B-spline / basis spline | 由次数、结点向量和控制点定义；基函数局部支撑，次数 p 与阶数 p+1 不同。 | [13][13]、[14][14] |
| de Boor 算法 | 在当前结点区间局部插值求值；两个参数方向可逐次计算张量积曲面。 | [13][13]、[14][14] |
| NURBS / non-uniform rational B-spline | 引入权重的有理 B-spline；四维齐次计算后再做除法，正权示例可精确表示圆弧和圆柱片。 | [13][13]、[14][14] |
| 曲率与挠率 / curvature and torsion | 描述曲线沿弧长的弯曲和空间标架的扭转；公式分别要求正则性及非零曲率。 | [13][13] |
| 法曲率 / normal curvature | 曲线弯曲在曲面法线方向的分量，随切向而变；不能与空间曲线曲率的大小混用。 | [14][14] |
| 主曲率 / principal curvatures | 正则曲面上一点的法曲率极值；H 为均值、K 为乘积，相等时没有唯一主方向。 | [14][14] |
| 射线 / ray | $r(t)=o+td$，加上合法参数区间。只有 $d$ 为单位方向时，$t$ 才等于沿线距离。 | [15][15] |
| 最近合法交点 / closest valid hit | 先过滤 `t_min <= t <= t_max`，再比较剩余根和所有物体；负根不是前方命中。 | [15][15] |
| 阴影射线 / shadow ray | 从偏移后的表面点查询到点光源前的有限线段；光后方物体不遮挡这束光。 | [15][15] |
| 自相交 / self-intersection | 新射线立即再次命中自身表面；[15][15] 用起点法线偏移与参数下限展示改善及其局限。 | [15][15] |
| 镜面反射 / specular reflection | 确定方向 $r=d-2(d\cdot n)n$；[15][15] 每次只延伸一条反射射线。 | [15][15] |
| 路径权重 / throughput | [15][15] 中沿反射链累计的材料镜面混合系数乘积；不是随机采样的概率密度。 | [15][15] |
| 路径追踪 / path tracing | 随机采样光传输路径以估计辐亮度；[第 15 章](?chapter=rays)的确定性镜面链与[第 26 章](?chapter=path-tracing)的漫反射随机路径使用不同的估计方式。 | [15][15]、[26][26] |

## 几何处理与建模

| 中文 / English | 含义与常见混淆 | 章节 |
| --- | --- | --- |
| 细分曲面 / subdivision surface | 反复细分控制网格形成的极限表面；有限步多边形仍是近似，增加采样点不等于执行细分规则。 | [16][16] |
| 拉普拉斯算子 / Laplacian | 本书离散符号为 $(Lx)_i=\sum_j w_{ij}(x_i-x_j)$；刚度矩阵、归一化算子与质量矩阵要分开。 | [17][17] |
| Dirichlet 边界条件 / Dirichlet boundary condition | 固定指定变量的值，消去对应自由度；不是在能量中加一个任意大的惩罚数。 | [17][17]、[29][29] |
| 二次误差度量 / quadric error metric, QEM | 累计到参考平面的平方距离，衡量边折叠候选代价；并非到原表面的精确距离。 | [18][18] |
| 重网格 / remeshing | 改变顶点分布与连接关系以调整网格质量；简化、细分和平滑分别只承担其中部分工作。 | [18][18] |
| 参数化 / parameterization | 为表面构造参数域坐标；保角、保面积与低长度畸变一般不能同时精确满足。 | [19][19] |
| 最小二乘保角映射 / least-squares conformal maps, LSCM | 最小化分片线性映射的离散保角残差，需约束消除零空间；不保证任意网格全局无翻折。 | [19][19] |
| 自由形变 / free-form deformation, FFD | 用外围控制格的插值变换内部位置；本书演示二维双线性控制格。 | [20][20] |
| 尽可能刚性形变 / as-rigid-as-possible deformation, ARAP | 交替估计局部旋转和全局位置，尽量保持局部边关系；不是整个物体只能做刚体运动。 | [20][20] |
| 三角测量 / triangulation | 在重建中由多条视线估计空间点。同一英文词在网格处理中也可译为“三角化”，指把多边形拆成三角形，两种输入与目标不同。 | [12][12]、[21][21] |
| 迭代最近点 / iterative closest point, ICP | 交替更新最近点对应与变换，依赖初始位置和重叠范围；不是全局最优的保证。 | [21][21] |
| 等值面 / isosurface | 标量场取同一值的点集；需要场值或重建规则，原始点云本身不足以定义每个体素的值。 | [21][21] |
| L 系统 / Lindenmayer system | 用并行字符串改写描述生长规则，再解释为几何动作；字符串、解释器和形状是不同层。 | [22][22] |

## 光传输

| 中文 / English | 含义与常见混淆 | 章节 |
| --- | --- | --- |
| 立体角 / solid angle | 一束方向在半径 R 的球面上覆盖的面积除以 R²，单位为球面度（sr）；整个球面为 4π sr，方向积分还可能需要余弦投影。 | [09](?chapter=texture-functions)、[23][23] |
| 辐射通量 / radiant flux | $\Phi$，单位 W；光通量是按人眼响应加权的光度量，单位流明。 | [23][23] |
| 辐射强度 / radiant intensity | $I=d\Phi/d\omega$，单位 W/sr。 | [23][23] |
| 辐照度 / irradiance | $E=d\Phi/dA$，到达接收面的单位面积通量，单位 W/m²。 | [23][23] |
| 辐亮度 / radiance | $L$，单位 W/(m²·sr)，保留传播方向与投影面积信息；不能与辐照度互换。 | [23][23] |
| 双向反射分布函数 / BRDF | $f_r=dL_o/dE_i$，单位 sr⁻¹；反射率 $\rho$ 无量纲，约束的是方向积分。 | [24][24] |
| Fresnel 反射 / Fresnel reflection | 界面反射比例随入射角、折射率等变化；折射方向由 Snell 定律决定。 | [24][24] |
| 辐射度 / radiosity | $B$ 为面元总出射辐射通量密度，单位 W/m²；漫反射假设下常按面元存储，$B_e$ 为自发射项。 | [25][25] |
| 形状因子 / form factor | $F_{ij}$ 是面元 i 出射能量到达面元 j 的比例；满足面积加权互易关系。 | [25][25] |
| 蒙特卡洛估计 / Monte Carlo estimation | 用随机样本及其概率密度估计积分；有限深度截断偏差不会因只增加样本数而消失。 | [26][26] |
| 重要性采样 / importance sampling | 调整采样密度并使用相应权重，目标是降低方差；不能只多采样亮处而省略密度校正。 | [26][26] |
| 包围体层次 / bounding volume hierarchy, BVH | 用层级包围体排除不相交候选，叶节点仍进行实际求交。 | [27][27] |

## 图像处理、计算摄像与风格化

| 中文 / English | 含义与常见混淆 | 章节 |
| --- | --- | --- |
| 抠图 / image matting | 从颜色与额外约束估计前景、背景及混合比例；单个 RGB 观测不足以唯一确定全部未知量。 | [28][28] |
| alpha 合成 / alpha compositing | $C=\alpha F+(1-\alpha)B$；本书颜色为线性 RGB，alpha 是权重而非 sRGB 颜色。 | [28][28] |
| 泊松图像编辑 / Poisson image editing | 用梯度目标和边界颜色求内部像素；边界决定解的整体颜色关系。 | [29][29] |
| 删缝 / seam carving | 动态规划寻找低代价连通路径并删除；保护区域与梯度能量会改变选择，不能保证语义完整。 | [30][30] |
| 单应 / homography | 平面之间的可逆投影关系，用齐次矩阵表示；一般有深度视差的场景不能由一个单应精确配准。 | [31][31] |
| 随机采样一致性 / RANSAC | 从小子集拟合候选并统计内点；输入对应关系可能来自另一个匹配过程。 | [31][31] |
| 光圈数 / f-number | $N_f=f/D_a$，无量纲；数值增大意味着同焦距下光圈直径缩小。 | [32][32] |
| 弥散圆 / circle of confusion, CoC | 离焦光束在传感器平面形成的足迹尺度；与衍射斑不同。 | [32][32] |
| 去马赛克 / demosaicing | 从颜色滤波阵列的不同通道样本重建彩色图像；不是每个像素原本已经测到完整 RGB。 | [33][33] |
| 色调映射 / tone mapping | 将场景动态范围映射到显示范围；与线性 RGB 的 sRGB 编码分属不同步骤。 | [33][33] |
| 正则化 / regularization | 在数据拟合外引入先验偏好，缓解欠定或病态；不能自动恢复未观测信息。 | [34][34] |
| 光场 / light field | 同时记录位置与方向维度的光线信息；移位叠加可重对焦，但受采样、遮挡等限制。 | [34][34] |
| 同色异谱 / metamerism | 不同光谱在同一组通道响应下得到相同测量；RGB 相同不意味着光谱相同。 | [34][34] |
| 非真实感绘制 / non-photorealistic rendering, NPR | 按边缘、色阶、笔画等表达目标组织图像；风格化仍需要几何、滤波与时间一致性。 | [35][35] |
| 纹理合成 / texture synthesis | 根据样例及匹配规则生成新的纹理区域；[第 36 章](?chapter=texture-synthesis)使用纹理块与最小代价接缝。 | [36][36] |

## 动画与模拟

| 中文 / English | 含义与常见混淆 | 章节 |
| --- | --- | --- |
| 关键帧 / keyframe | 指定特定时刻的状态，插值规则决定中间过程；经过相同端点不保证相同速度。 | [37][37] |
| 球面线性插值 / spherical linear interpolation, SLERP | 单位四元数间的球面插值；本书存储顺序为 $(w,x,y,z)$，先处理同姿态的双重表示。 | [37][37] |
| 正向运动学 / forward kinematics, FK | 从关节参数沿层级求末端位置与姿态。 | [38][38] |
| 逆向运动学 / inverse kinematics, IK | 从目标末端求关节参数，可能多解或不可达；本书解析示例为平面两连杆。 | [38][38] |
| 线性混合蒙皮 / linear blend skinning, LBS | 按权重混合包含绑定姿态逆变换的骨骼矩阵；权重和为 1 仍不保证旋转部分保持刚性。 | [38][38] |
| 数值积分 / numerical integration | 以有限时间步近似动力学演化；稳定、准确和能量性质分别判断。 | [39][39] |
| 粒子系统 / particle system | 以位置、速度、寿命等状态组织大量个体；视觉发射器与受力模拟可以采用不同更新规则。 | [39][39] |
| 群体行为 / flocking | 根据局部邻域更新分离、对齐与聚合等运动；同步更新避免循环顺序改变同一步的输入。 | [39][39] |

## 符号速查

同一个字母在不同章节可能有不同作用，公式旁的定义优先。下面列出跨章最容易混淆的几组。

| 符号 | 常用含义 | 不要混为一谈 |
| --- | --- | --- |
| $p$, $v$, $n$ | 点、方向向量、法线；[07][07] 的 $v$ 特指表面指向相机的单位视方向 | near 有时也简写 $n$，请结合上下文。 |
| $M,V,P$ | 模型、视图、投影矩阵 | [10][10] 的标量可见率也写 $V$，它不参与坐标变换。 |
| $w$, $1/w$ | 齐次坐标第四分量及其倒数 | 与普通插值权重 $\lambda_i$ 不同。 |
| $\lambda_i$ | 屏幕三角形重心权重 | 透视正确插值中还需结合每个顶点的 $w_i$。 |
| $z_{\rm view}$, $z_{\rm ndc}$, $D$ | 相机空间 Z、除以 w 后的 Z、归一化深度缓冲值 | 本书前方 $z_{\rm view}<0$，$z_{\rm ndc}\in[-1,1]$，$D\in[0,1]$。 |
| $d$, $t$ | 射线方向、射线参数；[06][06] 的 $d$ 则是正轴向距离 | [13][13] 的 $t\in[0,1]$ 是曲线参数，也不是弧长。 |
| $u,v$ | [第 08 章](?chapter=textures)的纹理坐标；[第 12 章](?chapter=geometry)的曲面参数 | 不能由字母推断单位；纹理域通常归一化，椭球经纬参数用弧度，[13][13]、[14][14] 的曲线与曲面示例参数通常在 `[0,1]` 内。 |
| $\ell,h$ | 指向光的方向、光与视线的半程方向 | `h` 也可能表示差分步长或图像高度。 |
| $k_d,k_s,q$ | 漫反射系数、高光系数、高光指数 | [15][15] 的球求根代码也用局部变量 `q` 表示稳定根公式的中间量。 |
| $b$, $\varepsilon$ | [10][10] 的深度 bias；[15][15] 的世界空间起点偏移与单位射线参数下限 | 单位不同，不能直接共用一个数值。 |
| $N,f_s,\nu$ | 样本总数、采样率、信号频率 | 空间频率的单位可为周期/像素，时间频率可为周期/秒，须与采样率一致。 |
| $+\infty$、`NaN` | 无命中深度、无定义属性的标记 | 不是可直接带入光照的有效表面数据。 |
| $L$, $\widehat L$ | 几何处理中为刚度矩阵与归一化离散算子 | 光传输中的标量或 RGB 量 $L$ 为辐亮度，依据对象类型与单位区分。 |
| $\omega_i,\omega_o$, $h$ | 指向来光处、观察方向的单位向量及半程向量 | 与朝表面传播的入射射线方向相反；不是位置或速度。 |
| $B$, $B_e$, $E$ | 面元总出射度、自发射项、入射辐照度 | 同为 W/m² 也不意味着物理作用相同；图像合成中 B 则明确定义为背景色。 |
| $\alpha$, $\eta$, $\sigma_a$ | GGX 分布参数、折射率、吸收系数 | 抠图 alpha 为混合权重；分布参数与光学透明度没有默认对应关系。 |
| $\lambda$, $\lambda_i$ | 局部定义的正则/平滑强度，或重心坐标分量 | 相同字母不意味着参数可跨模型直接共用，步长须符合对应算子的尺度。 |
| $t$, $T$, $u=t/T$, $\Delta t$ | 动画物理时间、区间时长、归一化进度、积分步长 | $d p/dt$ 与 $d p/du$ 相差 T 因子；曲线的归一化参数不默认以秒计。 |
| $q=(w,x,y,z)$ | 单位四元数，w 为标量部分 | 该 w 不是点的齐次分量，四元数与位置不能按同一种方式做透视除法。 |
