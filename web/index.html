      书中演示 · 操作指南
      
观察、编辑、验证。

      

        
动态推导

        

          彩色圆环是可拖动的控制点，方向键微调、Shift 精调。Ctrl / ⌘ +
          滚轮缩放；拖动空白处、中键或按住空格平移；F
          适配。轻按空格播放，时间轴与逐步按钮控制构造过程；离开视口后自动暂停。
          触屏先选“操作图形”，结束后选“完成操作”恢复书页滚动。
        

        
三维观察

        

          成像视角直接操纵拍摄相机；空间剖解从外部看场景。空白处拖动或 Alt
          拖动旋转，Shift 拖动平移，滚轮缩放。
        

        
直接编辑与对照

        

          拖动物体表面平移，W/E/R 使用坐标轴工具；点击 Python
          图像联动选中对应物体。A/B 分界比较两个通道，定格 A
          保留当前结果供后续操作对照。
        

        
二维编辑

        
拖动控制点 · 空格拖动平移 · 滚轮缩放

        
精确参数

        

          左右拖动数值，Shift 精调；双击或 Enter 精确输入，方向键微调。XYZ
          与场景手柄共用同一组参数。
        

        
撤销 / 取消

        

          Ctrl / ⌘ Z 撤销，Ctrl / ⌘ Shift Z 重做；一次连续拖动算一步，Esc
          取消当前拖动或输入。
        

        
相机

        

          参考点平移整台相机，镜头角度相对当前观察方向；选中透视相机后 Alt +
          滚轮调整视野。
        

        
布局

        

          ⛶ 放大或还原演示；“成像 /
          空间”切换观察对象，“双视图”并排对照。“参数”打开检查面板，实验、对象和像素各自保留状态。
        

        
源码

        

          综合演示下展开本章完整源码；动态图右上角的 〈/〉 定位到对应的 Python
          构造函数。
        

      

      

        这些演示是运行中的程序。WebGL 负责即时三维观察与操作预览，Python / NumPy
        计算成像与数值结果。
